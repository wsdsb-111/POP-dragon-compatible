# 1.3.2 王座龙血实施记录（2026-10-27）

状态：已落地待整合的脚本与测试源码；本代理未运行 Node、CK3、组包或安装，不构成实机／回归 PASS。设计与用户后续约束见 `1.3.2-fusion-design-20261027.md` 第0节。

## 已落地内容

新增独立 `patches/wyvern-ascension`。没有直接改 capture／kings 原文件，而是在新模块用显式晚加载定义接入旧API：

- 旧 `mm_wyvern_legendary_blood_reward_effect` 转入真击杀后端；来源为准确死者引用，预约 exact claimant，只追加吸收来源，不伪造生物祖源。
- 旧 `mm_wyvern_bathed_in_dragon_blood` 保留全部原 gameplay 字段和 flags，作为“王座执掌之血”完成态；旧持有者不降级、不补侵蚀，不为缺源旧档猜造龙形。
- 新 `mm_asc_usurper_blood` 使用两个原生 tracks，年度侵蚀 +10；每个日历年最多一次仪式，250金币／250虔诚／100威望换融合 +20。年度与付款锁均用原生 `current_year`。
- 单一 resolver 在写终结 outcome 之前验证死者、claimant 和当前 incarnation。正常先满者立即唯一结算；异常预先双满按侵蚀优先。来源冲突只记录诊断与提示，不能先写结局再失败，也不继续收费。
- 0／25／50／75 侵蚀阶段有独占的真实外交／健康／好感 modifier；低语每个年度最多一次掷骰，以专属偏执／狂乱 modifier 与实际压力反馈。不修改原人格／疯狂／疾病特质。结束只清本模块负面，延迟低语选项再次复核候选状态。
- 两个结局都获得 `mm_asc_dragon_body` 与同 ID 可逆化形。融合默认人形、保留本人名字和王权身份；侵蚀默认龙形、复制实际来源姓名、承接来源王权。形态切换决议只改互斥 form flags，零属性／父母／祖源／姓名写入。
- 十个固定人物仍为不可变席位锚；`mm_asc_current_incarnation` 指向现任，derived `mm_asc_seat_<ID>` global scopes 供唤醒目标与前置条件解析。转位、双生互指、complete／皇位与每日恢复接线不复活死者。
- 旧命令吞噬入口与新王本人吞噬入口共用 `mm_asc_unite_twins_effect`。双方当前合法、已醒、同座、互指且一次 united 未用才执行；新增自吞排除。
- 新 body 不带原野兽物种的禁继承／禁婚／禁子女／禁领军。持有者只入 `mm_asc_sovereigns`，不进 `myv_living_wyverns`，避开野兽人口上限的直接 death。晚覆盖的四个非人维护后端仅对新 body 跳过；普通 MYV 后端保留原内容。
- canonical `myv_is_wyvern` 扩展后仍会命中原 MYV 的活动／任职限制，已额外覆盖 `can_hunt_trigger`、`court_position_employee_shown_trigger`、当前 capture 版 `can_be_knight_trigger`，只让 body 进入原普通规则，不绕过健康／政府／性别／任职限制。body 两形都保留正常政治人物页；原野龙猎杀交互的显示与执行只准 canonical wild，避免把新君主显示为猎杀对象。

## 对外接口与跨模块合同

| API／字段 | 合同 |
|---|---|
| `mm_asc_receive_blood_effect` | 击杀者 scope；调用前存在真死者 `scope:myv_slay_wyvern_target` |
| `mm_asc_yearly_effect` | 当前候选 scope；按 `last_erosion_year` 去重 |
| `mm_asc_perform_ritual_effect` | 当前候选 scope；再次验证后才锁年／扣款／推进 |
| `mm_asc_resolve_effect` | 唯一终结后端；先 source claim 再 outcome |
| `mm_asc_change_form_effect` | 只允许完结且可靠血源的 body；只切 form flags |
| `mm_asc_unite_twins_effect` | 幸存者 scope；本人入口与原羁绊命令共用 |
| `mm_asc_blood_source` | 本次竞赛准确血源，后续击杀不重置 |
| `mm_asc_source_size/color` | 来源原生具体身量／颜色的快照 |
| `mm_asc_visual_family` | 1火／2地／3海／4天／5白／6黑；0仅实际原色回退 |
| `mm_asc_outcome` | `flag:fusion` 或 `flag:dragon`；不存在第三个繁育／开族分支 |
| `mm_asc_dragon_form` | 龙形；与 `mm_wyvern_human_form` 互斥同步 |

lineage 接口：在 source scope 调用 `mm_dragon_append_absorbed_origin_effect = { TARGET = scope:mm_asc_claimant }`。其内部去重、登记分支并保留生物 origins。侵蚀接位者保留原 mixed tier／generation／多源，lineage 已将 true／royal 判断置于混血继承路径之前；融合 body 不算真正龙族亲本或王族。

模型接口由模型代理负责 `gfx/genes` 与 portrait 桥：body＋龙形 flag 必须实际选中真实来源六系模型／颜色与对应 size，清除龙形 flag 时恢复原人物人形 DNA。不能将本记录的字段存在当作外观验收。
