# 1.3.22 圣物插画接入

七张输入来自用户桌面“圣物插图”，原稿已逐字节归档到 `artwork/dragon-relics/illustrations/originals/`，不改动桌面文件。使用内置 imagegen 逐张去除背景、金色矩形画框和展示支架，保留圣物本体、飘带、链饰和附着光效。透明 PNG 归档于同目录 `cutouts/`；每张实际提示词及原始输出路径记录在 `inputs.json`。

提示词共同约束：仅抠图，保留原设计、纹理、配色、光照、视角；去除蓝色背景、外围金框及对应底座/支架；背景及物件间隙使用真实透明 alpha，不新增文字或构件。没有使用外部付费 API 或 CLI。

`scripts/build-dragon-relic-illustrations.py` 只进行透明图裁框、等比缩放及 DDS 转换，不承担背景编辑。每张适配 240×240 原生帧，主体置于中央216×216区域；四个相同帧横排为960×240 DXT5，避免品质选择截断图案，透明区域继续显示原版品质背景。

七件圣物的个人和宫廷版本均使用对应插画图标。个人版本保持原生资产绑定，自制模型仍仅绑定宫廷重铸版本；模型、材质、全部效果及圣地机制保持原字节。原图、透明图、游戏图和预览哈希及名称映射见 `artwork/dragon-relics/illustrations/manifest.json`。
