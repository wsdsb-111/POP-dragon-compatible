# 1.3.5 龙王体长、体重与承伤（2026-10-27）

本轮仅修改独立多 Mod 兼容补丁，不修改 VOTC 应用或原作者 Mod。体重参考来自用户本轮两张设计图；海洋与水之王仍为利维坦、贝西摩斯，埃吉尔仍为合一名。

## 体长与体重

原生数值体长当前没有三十米硬上限；模型第十档使用三十米阈值，与数值体长不同。原生存储一点为0.1米。这里提高实际物理体长，同时在提高前保存模型档位，保留原有模型大小；不修改网格、骨骼、动画或鳞色。

王族质量为 `参考体重 × (实际体长 / 参考体长)^3`。普通龙为 `100吨 × (实际体长 / 30米)^3 × 体质系数`，虚弱/正常/强壮分别0.85/1/1.15。王族独立构造已包含身体密度，不重复乘体质系数。体重由当前体长即时派生，沿用原生年龄成长，不另存一个容易过期的体重变量，也不写入人类肥胖体重。正常体质0.5米幼龙约0.463千克。

主龙族面板在体长与战斗力之间增加体重栏；一吨以下用千克，其余用吨，提示展示实际质量倍率。原有面板除新增一栏外保持原字节，四个属性共用原横排。布局是否在实机最小窗口下需要进一步缩字，仍待渲染验收。

## 战斗联动

- 敏捷质量倍率：`1 / (1 + 体重吨数 / 5000)`，范围0.35–1；保留原生体长、性情、协调、年龄、眼伤、翼伤、后肢伤、尾伤与激怒因子，最终取整前仅乘一次。
- 部位伤势倍率：`1 / (1 + 体重吨数 / 3000)`，范围0.20–1；接入空战受击、针对部位攻击、坠落以及战场随机受伤四个已有后端。它减少实际部位伤势经验，不等同于所有死亡事件统一减免。
- 黑白皇仍先独立进行一次70%免伤判定；免伤分支不造成部位伤势，其余30%只应用一次质量减伤。不增加第二次免伤抽签；原生致死流程、每日恢复和普通龙每月恢复保持。
- 质量不直接增加基础战斗力。实际体长沿原生公式影响战斗力与喂食需求，因此百米龙也会需要更多食物。

例如黑皇12500吨：敏捷质量倍率0.35、伤势倍率0.20；白皇10000吨：0.35和约0.231；普通正常体质30米龙100吨：约0.980和0.968。质量下限避免完全不受伤或单由质量使敏捷归零，但其他原生因素仍可降低敏捷。

## 原作者龙族特征与王族分配

原生主要三组是体质（虚弱、正常、强壮）、协调（笨拙、协调、敏捷）、性情（温顺、警觉、凶猛），另有伤势、营养不良等状态；并非只有敏捷。原生强壮提供成长与战力，敏捷/警觉提供敏捷，凶猛提供战力。警觉与凶猛原本互斥。

## 接线及旧档

新局十位固定角色初始化后补齐；读档入口和原月度龙脉冲重复调用具有幂等性的补齐；主动吞噬、继位同时刷新。只处理十位固定角色和已有升华登记名单，不扫描全世界人物。

合法新ID王权继承者须有对应王座锚点与匹配王权，错配王座和仅有血脉分支的普通后代不获得王族体型或本能。可选升华模块通过公共桥提供来源身体判断，王族模块单独组包不会引用未定义的升华特质。

旧融合身体仅根据已有可靠血源补缺失/无效的体长、质量基准及模型快照；有效旧快照、更大的实际体长保留，未知血源不编造。仅融合身体不因此得到皇者本能或王权。
