## 黑皇与白皇的对人能力

三项能力使用人物右键互动，不在普通决议页选人：

| 圣物 | 互动 | 合格目标 |
|---|---|---|
| 黑鳞冠 | 龙之臣服 | 非龙王级的普通真龙 |
| 黑皇权柄 | 始祖毁灭 | 非龙王级普通真龙或混血 |
| 白色神谕之书 | 意识操作 | 活着且未获得黑白皇血脉免疫的人物，使用原生傀儡机制 |

飞龙 Mod 的专用头像通过 `ToggleFilteredCharacterInteractionMenu(..., 'myv_wyvern_interaction')` 打开筛选菜单，原圣物互动缺少该标签，确实可能被过滤。现在三项均加入对应标签，设置 `common_interaction = yes` 和较高优先级，使用实际存在的原版 `religious.dds` 图标，替换不存在的 `religious_interaction` 引用。

装备相应圣物且目标合格时显示入口；血脉、礼仪和冷却仍在有效性条件中检查，不因显示菜单而放宽。目标免疫及效果执行中的二次复核保留。没有覆盖飞龙 GUI 或修改原 Mod。

## 混血开局

用户已选择“从现有人物中随机选取携带者，按真实亲缘处理后代，保留姓名、家族和家谱”。

- 保留原五组文化列表及文化轮换抽取。每组最多选五名现有成年携带者，已有 House 只能成为一个起始家庭；合格候选耗尽则跳过，不新建人物、宗族或 House。
- 第一名成功选中的携带者为第一代，其余为第二代。存活后代沿生物亲缘逐代递减，最多第四代；现有自然出生和突变规则未改。
- 缓存现有活人后，对每个目标反向读取 `mother`／`real_father`，不依赖可能遗漏隐藏私生子的法律父亲子女迭代器。可经过死亡的中间祖先，但不修改死者；跨 House 的真实后代仍可继承。
- 不修改姓名、父母、真实父亲、House、宗族、年龄、文化、头衔或婚姻。不因配偶、同姓或同 House 旁系关系授予血脉。血脉携带者继续通过原归宗 hook 路由礼仪。
- 同一活人存在两条本轮种下的真实血缘时，追加去重祖源并保留较强代次；不覆盖原有非本轮混血。处理结束清理临时列表、计数和标记。
- 沿用新战役 pending 与既有初始化标记，只在新开局处理；不主动迁移用户已经保存的家庭。旧档加载语义和新开局耗时仍须 CK3 验证。
