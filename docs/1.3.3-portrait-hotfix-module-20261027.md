# 龙王图标与人形龙瞳热修记录

- 龙王与合一君主保留原 trait、buff 和 `first_valid` 动态结构。现有动态 `desc` 使用完整路径；本机游戏 `common/traits/00_traits.txt` 的 `faith_warrior` 等实际使用裸 DDS 文件名，因此改为同一格式，五个图标文件均已存在。游戏 `_traits.info` 文档的示例却写完整路径，故以实际实现为依据；须实机确认。名称和描述仍为原公共本地化键。
- 游戏 `gui/shared/icons.gui` 人物特质图标使用 `Trait.GetIcon(Character.Self)`；`shared/cooltip.gui` 中信条特质图标使用 `Trait.GetIcon(GetPlayer)`。因此两类界面的作用域不同，不将静态检查等同实际悬浮提示验收。
- 两性自定义眼睛实体补上原生 `male_eyes.asset` 和 `female_eyes.asset` 的 `portrait_entity_user_data/color_mask_remap_interval`。参考本机已安装 Mod 2243307127 的 `portrait.shader`，眼睛 diffuse alpha 是遗传色乘法遮罩，0 时保留 diffuse RGB。原逻辑将原生 alpha 覆盖回自定义金虹膜，可能使深色遗传眼色乘暗金色；现在只清除虹膜覆盖区域的 alpha，保留原有眼白纹理和遮罩，并由原纹理资产构建，无重新绘制。DDS 解码检查中心瞳孔黑色、虹膜样本 RGB 178/120/35 且 alpha 0。
- 人物有 `mm_dragon_pupils` 时，普通人类不再依赖 `mm_dragon_blood_human` 标记；原龙形仍排除，龙族人形标记继续允许。角、尾和鳞的选择逻辑未改。
- 未启动 CK3、未跑 Node 测试。须实机检查四座双生／合一图标及角色面板和悬浮提示、无作用域回退、黑白皇图标；检查男女与儿童及不同遗传眼色下的人类／混血金虹膜、龙形切换及角尾鳞。若提示错误选择玩家作用域，须单独评估引擎 GUI 限制。此记录不表示游戏内通过。

补充：双生和合一的动态描述使用 `first_valid`，无人物及未知王座回各自原描述，四座分别选择 `trait_mm_royal_fire_desc`、`trait_mm_royal_earth_desc`、`trait_mm_royal_sea_desc`、`trait_mm_royal_sky_desc`；上述新键由主任务提供本地化。原生 `00_traits.txt` 的 `education_intrigue_1` 使用同一种 `desc/first_valid/triggered_desc` 结构。

普通人物特质提示不应与信条特质组件混为一谈：`window_character.gui` 顶层载入 `CharacterWindow.GetCharacter`，特质列表使用 `icon_trait`；`shared/icons.gui` 的 `trait_icon_base` 连接 `character_trait_tooltip`，该模板的图标复用 `trait_icon_texture` 并以 `Character.Self` 获取，名称及完整描述也使用同一 `Character.Self`。因此该人物面板的原生接线无需修改；信条组件 `GetPlayer` 不是此提示的图标路径。具体运行时仍须验证。
