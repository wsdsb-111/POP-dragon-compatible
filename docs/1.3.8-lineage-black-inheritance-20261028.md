# 1.3.8 六系分支与黑血继承（2026-10-28）

## 分支串入原因及修复

用户以青铜与火系混血角色繁育后，婴儿额外得到白皇、黑皇分支。独立有限执行首先复现了问题：真龙登记会将龙王家谱中的黑白皇父母作为额外来源，并把源龙已有的`mm_dragon_bio_*`祖先标记无条件复制给后代。该逻辑六系共用，因此同时检查青铜与火、大地与山、海洋与水、天空与风、白皇、黑皇。

已知王座或创造归属的源龙，按其明确身份投影分支，不再因为自身保留祖先标记就向后代额外授予黑白皇等分支。王族向后代提供自身作为直接源龙，不把其历史来源清单当成另一次独立继承。新登记王族不再自动追加创造父母；已有精确来源列表、16槽投影、父母亲缘与升格前的合法历史来源不删除。

分支刷新对所有来源均有可用证据的角色重算生物分支，并移除没有依据的可见分支；后天吸收标记仍可驱动其本人拥有相应分支，但不混入生物遗传。未知来源或仅靠自身旧标记维持证据的自引用来源保守保留。真正由不同分支亲本带来的独立多源血统继续保留。

## 旧档范围

读档时只访问玩家、其存活子女及宫廷/访客中的混血角色；已有龙注册表沿原有流程更新。明确只记录一位火系等源龙、却误带黑白皇标记的旧角色会依据来源重算。不重新生成人物、不重抽血统等级、不改亲缘或吸收记录、不遍历全世界人物。

如果旧来源列表本身已明确保存黑白皇身份，单靠该列表无法判定是过去错误展开还是合法独立血缘，本轮保留而不猜测删除。没有可靠来源时也不捏造新祖源。此边界避免为修复单一截图而抹掉真正的跨系混血。

## 黑血新规则

用户本轮明确替代“不向后代传承”的旧规则：

| 繁育条件 | 子代结果 |
|---|---|
| 人类/混血繁育，任一非真龙亲本为黑血 | 黑血、S、A、B、C各20%，一次必得一种 |
| 双方都是黑血 | 仍只进行一次五选一，不增加抽取次数 |
| 黑血或其他人类混血与普通真龙直接繁育 | 固定S级，不被人类侧的10%或五选一覆盖 |
| 黑血或其他人类混血与具名龙王/皇者直接繁育 | 固定初代种，不被人类侧抽取覆盖 |
| 无黑血的普通混血繁育 | 保留逐代衰减及一次10%黑血突变；C级失败仍不保留活跃血统 |

黑血五选一使用五个权重均为20的原生`random_list`；不再叠加10%突变。双方的合法生物来源合并去重，等级选取不等于祖源切换；黑血本身不产生黑皇分支。新创建的人龙蛋固定S/初代种，不再冻结人类侧10%突变；既有蛋继续遵循其已冻结记录，不重抽已有结果。特质介绍同步更新。

## 验证

独立QA提供分支和黑血两组回归。分支回归先在修复前失败（`.build/v138-before.log`），修复后通过，覆盖六系全部预置污染、家谱保持、明确独立白/黑来源、吸收不遗传、未知/明确自引用来源、升格王族历史来源保持与读档定向修复。QA发现并帮助修复了自引用来源重算可能丢失证据、以及清空王族来源清单可能损伤合法历史的问题。

黑血回归覆盖五项权重均20、父方/母方/双方黑血、与普通及其他混血配对、来源去重、重复调用不重抽，以及黑血与真龙/王族在两个性别方向的普通出生和产蛋孵化。旧回归仅更新与用户新规则冲突的终端黑血和直接龙族人类突变断言，其他合同保持。

完整42组回归按384MB限制串行通过（`.build/v138-tests.log`），包括1.3.7人口保护与家族命名。原生脚本的条件和有限执行不等于实机；新血统结果、读档投影与界面显示仍待CK3运行验证。
