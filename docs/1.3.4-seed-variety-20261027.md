# 1.3.4 新局普通龙个体差异

## 根因与实现

1.3.3 的四王座种群循环对每条龙传入固定 `AGE = 30 SIZE = 80`。创建器虽已独立抽取体质、协调、性情与颜色，固定年龄和体长仍令年龄、体型以及以体长为主要输入的数值趋同。源码中的体质与协调是 `physical` 特质；现行人类特质清理只按指定类别清除，未见该路径直接删除这两类龙特质。是否在实际新局中正确保留，仍需 CK3 验证。

种群使用专用 `mm_royal_create_seed_wyvern_effect`，避免猜测脚本宏参数能否传递年龄区间，保留普通 `myv_create_wyvern_effect` 的 AGE/SIZE 合同及其他调用。每条创建时由 CK3 原生 `age = { 12 150 }` 抽年龄、`gender_female_chance = 50` 抽性别；体质、协调、性情均各三项等权，颜色继续调用原生抽取。个体成长系数独立等权取 0.9、1、1.1。

体长内部单位为 0.1 米：`5 + (myv_wyvern_expected_size_from_age - 5) × myv_wyvern_growth_physique_multiplier × 个体成长系数`，再经 `myv_wyvern_sanitized_size` 下限处理。原生体质成长系数为弱 0.85、普通 1、强壮 1.15；基准年龄曲线 12、20、50、100、150 岁对应 58、90、180、250、280。该公式按年龄和体质模拟已积累的成长，个体系数仅应用于初始大小，后续每年仍由原生成长逻辑处理。

创建后沿用原来源登记、身份维护、巢穴初始化、画像刷新和战斗力刷新；不直接随机写入战斗力或敏捷。普通战斗力由大小曲线、体质（0.9/1/1.1）、性情、伤病和饥饿等计算，敏捷由大小曲线、年龄、协调（0.9/1/1.1）、性情和伤病等计算。原普通龙 `life_expectancy = 200`，无永生；本改动不调整寿命。四组各 5–10、源王关系、种群上限保护及一次性初始化逻辑不变，具名龙王不经过本创建器。

## 验证与边界

静态对照了现行 MYV 的自然创建、年龄曲线、体质、协调、身份及战斗计算，并检查了当前补丁的普通种群保护。尚未运行 CK3、Node 或独立 QA；区间语法沿用 MYV 自然生成的 `create_character` 原生形式，但本实现的实际新局结果仍待实机验证。应抽查多次新局各组数量、不同年龄与尺寸、性别及三个特质、血缘和初始巢穴，并核对战斗力、敏捷与实际死亡行为。随机抽样不保证每一组必定出现所有年龄或性别。
