# 血脉分支与原生龙族显示修复

- 四项王权由血脉模块的可覆盖王族触发器判定；刷新时移除六种分支特质但不删除来源变量。普通龙的已登记创造归属按 1 火、2 地、3 海、4 天显示分支及两位源龙王；其生物后代继续通过既有来源投影继承，创造关系不改写父母。
- 创建登记由龙王模块的 `mm_dragon_creation_source_hook_effect` 调用 `mm_royal_assign_creation_effect`，再由真龙登记刷新；具名王族旧档须执行真龙登记或分支刷新才能清除已存在的分支特质。旧真龙若没有可信创造记录，不应随机补造归属。
- 原生身体名称与性别提示放在 `localization/replace`，以覆盖上游同名本地化。传奇身体称为龙王，但具名王位依王权特质，保留已有传奇血脉来源特质。
- 仅静态核对括号与 UTF-8 BOM；未启动 CK3，实际本地化优先级、人物界面和旧档迁移效果均需实机验证。
