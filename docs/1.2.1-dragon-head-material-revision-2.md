# CK3 龙头战利品材质二次修正施工文档

**目标：**
将当前偏黄、偏亮的龙头修正为灰橄榄绿龙皮、深褐角质与灰褐色腹侧，保留其作为真实巨龙头颅战利品的生物质感。

## 1. 当前问题

当前模型已成功导入
CK3，鳞片细节和整体陈列效果基本合格。但实机颜色偏亮、偏黄，读感更接近黄绿色风化石雕或古铜化石，而不是真实西方龙皮肤。

本轮只修正色相、明度和材质分区，不重做模型。

## 3. 具体修改要求

### 主体鳞片

1.  将偏黄的浅橄榄褐修正为明确可辨识的灰橄榄绿。
2.  优先纠正色相，再视实机效果适度降低明度；不要单纯把整个模型压暗。
3.  保留原有鳞片细节和法线起伏。
4.  凸起鳞片边缘可轻微提亮，但不能形成黄色或金色轮廓。
5.  保留细微色差，避免整颗头统一染色。

### 鳞片缝隙与褶皱

-   用深灰绿强调鳞片层叠关系。
-   重点检查眼周、鼻翼、嘴角、颈部褶皱和棘刺根部。
-   阴影必须保留细节，避免压成纯黑。
-   不要用过度锐化制造不自然的高反差边缘。

### 下颌与喉部

-   使用灰褐橄榄色，与头顶硬质鳞甲拉开区别。
-   保留褶皱细节，体现皮肤的柔韧和层叠感。
-   避免明亮黄褐色，防止暖光下再次出现石雕感。

### 龙角、棘刺与牙齿

-   角和棘刺应独立于主体皮肤：根部深褐，中段中褐，尖端轻微提亮。
-   角质应干燥、坚硬，并保留纵向纹理。
-   牙齿使用旧象牙色，牙根略暗，避免纯白塑料感。
-   嘴部软组织使用低饱和灰褐色。
-   不添加大面积鲜血、黏液或腐烂效果。

## 4. 材质要求

### Base Color / Albedo

本轮优先调整底色贴图：

-   主鳞片呈灰橄榄绿，而不是黄绿或金黄。
-   受光区域只做克制的亮度变化。
-   深层缝隙使用深灰绿。
-   下颌、角、牙齿和嘴部软组织保持独立的颜色逻辑。
-   允许少量自然斑驳，但避免过度污渍和高频噪点。

### Roughness

仅在当前资源与材质工作流支持时调整：

-   鳞片：中等粗糙度，略有硬质反光，但不能湿亮。
-   褶皱与深层缝隙：更粗糙，避免油亮黑线。
-   下颌：偏干燥的皮革质感。
-   龙角：粗糙、干燥的角质感。
-   牙齿：略比角光滑，但仍然旧化、低光泽。

不要在未确认 CK3 材质如何读取贴图通道前，假定某个通道必然对应
Roughness。

### Normal / AO / Cavity

-   保留现有法线和模型细节。
-   只有在检查后确认细节不足时，才调整 Normal 或 AO/Cavity。
-   不要重复叠加法线细节造成表面过度粗糙。
-   不要把 AO 当作整体变暗工具。

## 5. CK3 实机适配

1.  以游戏实际引用的贴图和材质配置为修改对象，不要只看外部贴图预览。
2.  修改后在与当前截图相同或相近的宫廷环境中验证。
3.  同时检查正常观看距离和近距离细节。
4.  若实机仍偏黄，先检查颜色空间、贴图通道和光照影响，再小幅修正色相。
5.  不要为了追求外部预览颜色而过度压暗贴图。

## 6. 实施约束

1.  先检查项目中实际被宝物引用的模型、贴图、材质和资源路径，确认修改对象正确。
2.  优先修改现有贴图，不要无必要地重建材质或替换模型。
3.  不修改模型几何、底座、宝物位置、宝物定义或其他游戏逻辑。
4.  不覆盖原始资源；修改前保留可回滚备份。
5.  不引入未经确认的新工具、贴图格式或材质通道约定。
6.  完成后报告实际修改的文件、贴图、颜色参数和验证结果。
7.  如果当前材质不支持预期的 Roughness
    或其他通道，应说明限制，不要声称效果已生效。

## 7. 验收标准

-   [ ] 第一眼能识别出灰橄榄绿龙皮，而不是黄色石雕。
-   [ ] 主体鳞片有清晰但克制的层次。
-   [ ] 下颌与喉部和头顶鳞甲有明确色差。
-   [ ] 龙角与棘刺呈深褐角质，不再与皮肤融为一体。
-   [ ] 牙齿为旧象牙色，而非纯白。
-   [ ] 暖色宫廷光照下仍保留绿色倾向，不明显偏黄或偏金。
-   [ ] 没有重新出现暗红烧焦感、塑料湿亮感或过度压暗造成的细节丢失。
-   [ ] 模型、底座、宝物配置和其他游戏逻辑保持不变。
-   [ ] 修改后的资源已在 CK3 实机中验证。

## 8. 给 Codex 的执行摘要

请基于当前 CK3
龙头宝物资源进行第二轮材质修正。当前版本偏亮、偏黄，像黄绿色风化石雕；目标是修正为灰橄榄绿的真实西方龙皮。

优先修改 Base Color：主体鳞片 `#586347`，凸起鳞片 `#74805B`，次级鳞片
`#4D5940`，缝隙 `#30392D`，下颌 `#74745F`，龙角从 `#4B4035` 向 `#91816A`
过渡，牙齿 `#D2C39F`。

先检查实际生效的贴图、材质和颜色空间，再进行修改。保留现有模型细节、法线、底座和宝物配置；不要无必要地重建材质，也不要把整个模型统一压暗。只有在现有资源确实支持且有必要时，才调整
Roughness、Normal 或 AO。

完成后在 CK3
实机中验证。最终效果应为灰橄榄绿鳞片、深褐角质、灰褐色腹侧的古老西方巨龙头颅战利品，而不是黄色石雕、木雕或烧焦尸体。
