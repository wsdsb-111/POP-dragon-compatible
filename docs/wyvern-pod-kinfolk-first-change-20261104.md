# 兽嫡子女首次化形决议

按用户选择，由成年玩家为自己当前所有符合条件的未成年兽嫡子女补上原生觉醒标记；免费、无 AI 自动使用。仅加入飞龙＋黑暗亲王专用包。

## 使用与边界

决议名为“引导兽嫡子女觉醒”，使用游戏原有的宗教决议插图。至少有一个活着、未满16岁、拥有 `kinfolk` 且尚无 `fera_first_change` 标记的子女时，成年玩家可见并可执行。已是化兽族裔、换生灵或遗传血仆的孩子排除，后两者与原生事件的排除条件一致。

执行只给符合条件的当前子女添加 `fera_first_change`，不立即变更种族，不改血缘记录 `fera_type`、混血种等级、祖源、信仰或家谱。已有标记的子女跳过。处理完后因没有合格子女而隐藏；将来有新的合格子女时可再次使用。未覆盖成年兽嫡、廷臣、孙辈或其他非子女人物，也不自动为未来出生者添加标记。

黑暗亲王原文件 `common/scripted_effects/POD_child_birth_effects.txt` 给兽嫡新生儿按 `fera_shapeshifter_chance` 概率赋此标记。该值在 `common/script_values/POD_fera_values.txt` 中基础为25，父母种族、AI领主亲属和建筑等继续修正，并非固定50%。本次未改变出生概率。

原生 `common/on_action/childhood_on_actions.txt` 的 `on_16th_birthday` 排入 `POD_fera_maintenance.2`。事件要求兽嫡与原生标记，排除换生灵和遗传血仆；使用已有 `fera_type` 确定化形种族，缺失时原版回退狼人。本决议沿用该原生处理。若在成年前通过其他途径改变了种族，能否化形仍由原版届时的事件条件决定。
