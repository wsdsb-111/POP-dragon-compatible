# 1.1.1 追加：圆形地图按钮与飞龙对话入口（2026-10-23）

用户反馈：气候／人口被拆成独立矩形按钮，打开右侧决议栏时有时又混入县领按钮；飞龙头像右键菜单没有VOTC私人对话入口。本轮仅改独立兼容Mod，版本沿用1.1.1，原Workshop及游戏文件不改。

## 修改

1. 移除独立工具栏中的气候／人口矩形按钮。在当前CK3的gui/shared/mapmodes.gui中，沿原生icon_button_mapmode类型向三枚法理皇冠所在行添加气候／人口两枚圆形按钮，保留原图标、tooltip、地图切换、WoC脚本GUI、可用性及按下状态。原生宿主宽度170改为250，高度95保持；五枚38像素按钮、间距-3、右距15及50像素领地图标间留7像素。所有原地图模式、快捷键和加号展开菜单保留。
2. 附加工具栏只保留县领人口／建筑及财政三项，定位到圆形地图组左侧。两个县领按钮除原holding_view及county_view_open条件外，增加Not(IsRightWindowOpen)，右侧决议等窗口打开时不混入。没有实机复现用户的状态切换，因此源码门禁及模型通过不等于该反馈已获得实机复现／修复证据。
3. 飞龙头像使用ToggleFilteredCharacterInteractionMenu(...,'myv_wyvern_interaction')；VOTC原mcc_interaction没有此标签，所以被筛掉。新模块wyvern-votc-dialogue仅在VOTC的mcc_interactions.txt增加filter_tags={myv_wyvern_interaction}。保留原私人分类、可用条件、外交距离、旅行及mcc_event_v2.1002流程，不更改飞龙头像，不解除其他人类交互的筛选，也不复制新事件实现。
4. 对话模块单独声明VOTC 3346777360依赖，并依赖wyvern模块。默认完整包现含六个模块／十一项依赖；仅--modules=wyvern时不包含VOTC交互，--modules=wyvern-votc-dialogue才引入该依赖和对话接线。用户当前播放集已启用Voices of the Court 2.0。

本轮仅恢复对话入口。飞龙不会因此获得完整的非人类Prompt、专用状态导出或新动作；实际对话仍走当前VOTC通用人物流程，不宣称已经完成飞龙语义适配。
