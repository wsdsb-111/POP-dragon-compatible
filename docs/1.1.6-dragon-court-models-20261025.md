# 1.1.6 龙宝宫廷展示模型（2026-10-25）

为德拉克斯尔和瑟林德增加独立原生三维展示资源，并接上原版库存的“重铸”流程。仅增加两条精确匹配自定义武器的 blueprint；无需覆盖原版重铸事件、普通宝物或共享 `sword_court`／`small_box` 视觉定义。

## 模型

| 武器 | 细节 | 几何 |
|---|---|---|
| 德拉克斯尔 | 龙首、红宝石眼、骨牙及角形护手；分面双刃与中央骨质镶嵌；螺旋缠皮握柄、切面宝石剑首 | 18,205顶点／27,452三角形 |
| 瑟林德 | 骨质反曲弓臂、30片独立鳞片、金属包边与箍环；缠绳握把、红宝石、端部角饰及实体弓弦 | 32,121顶点／51,884三角形 |

两件各含完整木质、金边与纹章陈列架，采用原生 `court` shader 和共享1024颜色／法线／属性贴图。以本机原版武器为参照，Y轴向上、正面朝-X，高度约116与119单位，地面在Y=0。court visual 不再附加 pedestal，避免支架叠加。库存原有图标保留；此资源用于宫廷展示，不替换人物手持和战斗动画。

[实际模型多角度预览](../artwork/dragon-weapons/models/contact-sheet.png)来自生成的真实三角网格与颜色贴图。可编辑 GLB/OBJ、纹理、预览和哈希见[模型目录](../artwork/dragon-weapons/models/README.md)，可使用[重建脚本](../scripts/build-dragon-weapon-models.py)重新输出。

## 原生重铸接入

原版 `common/artifacts/blueprints/_blueprints.info` 说明，重铸通过 `in_type + in_visuals` 匹配，再按 `out_type + out_visuals` 输出。原版 sword blueprint 只接受普通 `sword` 视觉，没有匹配本 Mod 的自定义视觉；也没有对应的普通 bow 宫廷 blueprint。仅制作新 mesh 或修改库存的模型绑定，无法让重铸后正确使用。

新增两条：

- `sword + mm_wyvern_dragon_sword` → `pedestal + mm_wyvern_dragon_sword_court` → `mm_dragon_draxel_court_entity`。
- `bow + mm_wyvern_dragon_bow` → `pedestal + mm_wyvern_dragon_bow_court` → `mm_dragon_serind_court_entity`。

前版已锻造、仍为库存武器且保留对应视觉ID的宝物也匹配，无需重新打造。仍须满足游戏原生重铸条件与费用，不增加第二套决议、不免费复制或返还材料，不自动把武器转成宫廷宝物。

两条 blueprint 的禁用属性与四档随机替换列表完整保留原版 `sword_to_court`。重铸后按原生规则将不适用于展示的 modifier 换成宫廷属性，不能预期保留整套战斗词条。原生按整项 modifier 判断；本 Mod 固定属性打包在单一 modifier 中，因其中包含勇武等禁用字段，整项会被原生替换。此次不改武器装备时的固定／随机属性，也不另做词条补偿。

原版衰坏事件 `artifact.1001` 使用另一个 inline effect，会把剑改为共享 sword_court、弓落入small_box。当前自定义武器 `decaying=no`，本轮接的是手动重铸 blueprint，不覆盖该衰坏事件或扩大所有宝物的视觉规则。

## 验证边界

新增独立QA解析两条 blueprint，与冻结的原版 sword blueprint 逐AST比较，只有ID和四个输入／输出字段不同；核验输入精确匹配、实体与纹理绑定、二进制顶点／索引／法线／切线／UV、正面绕序、包围盒、哈希及GLB/OBJ。CI使用仓库fixture，不依赖本机D盘。

独立二进制参考 reader 与真实网格多角度渲染另行检查。自动化通过只代表结构和资源验证；原版重铸窗口、宫廷实际陈列方向／光照／尺度和重铸后的原生属性替换，仍需真实CK3验证。
