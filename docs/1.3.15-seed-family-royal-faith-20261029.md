# 1.3.15 新局混血家庭、龙王归宗与黑皇称谓修复

## 本轮问题与修复范围

用户截图显示24岁和21岁的新局生成混血兄弟分属云、吕等不同家族；随后确认是刚开新局生成。本轮修复生成规则，不对无充分身份标记的既存人物做全世界家族重写。

### 混血家庭

当前CK3 `_scripted_character_templates.info:181-189` 将 `dynasty` 定义为generate/inherit/none/default等选项，而 `dynasty_house` 接受家族键或House scope，且优先于dynasty生成/继承。旧代码却在子女创建参数中写 `dynasty = scope:mm_dragon_seed_founder.dynasty`，没有通过原生House参数指定父家族。该脚本类型与当前原生接口不符；当前日志没有直接记录该行的无效枚举错误，不能声称已从日志证明全部引擎执行过程。

新代码在父亲建立独立宗族/House并命名后保存实际House scope，两名子女均以 `dynasty_house = scope:mm_dragon_seed_house` 创建；创建返回后再次写入该House。每次生成下一户先清掉前户的临时House scope，不靠姓氏或龙血祖源把不同人合族。

父亲与两名生成子女属于同一House和宗族。母亲保留自己的出身家族或低出生身份是正常规则；本轮不强行改母亲宗族，也不增加未经要求的婚姻关系。父母及生物父亲链接保留，普通自然出生、母系婚姻和合法分家规则保持。没有新增不使用的持久修复标记或猜测旧档迁移。

**家庭生成修复须在新开局验证。** 已经生成并存入存档的家庭不会因此自动重建或改姓；若要保留某个既存家庭，需另行精确定位和审查。

### 十王与王座继承者的礼仪

旧路由会先保留任何与生物多源相符的当前礼仪，这适用于普通多源混血，却不能决定实际龙王的王座信仰。现将王族身份放在最高优先级，随后才执行原混血归宗规则：

| 身份 | 对应礼仪 |
|---|---|
| 黑皇 `mm_royal_black_emperor` | 始祖正统派 |
| 白皇 `mm_royal_white_empress` | 白皇神谕派 |
| 龙王实际王座1 | 铸火宗 |
| 龙王实际王座2 | 冥府宗 |
| 龙王实际王座3 | 怒潮宗 |
| 龙王实际王座4 | 风暴宗 |

王族不会因旧礼仪、其他 `bio_*` 祖源、吸收能力或身体原有分支抢占当前王座归属。合法王族资料修复在同步身份后调用既有可选信条hook，确保初始化和王座继承路径及时归宗；未启用信条模块时沿用空hook。普通多源混血仍保留任一与生物祖源相符的当前礼仪；吸收分支不授权归宗；普通黑血不等于黑皇。

### 简介

龙之信条简介、宗教简介、始祖正统派简介三项中文“黑王”改为“黑皇”，英文同步使用Black Emperor。未改其他名称或属性。
