## 繁育、父母与四代来源

### 人龙半龙蛋

成年男性持有沐浴龙血，对有羁绊、已成年且处于人形的女性已驯服龙使用“协商龙血繁育”。对方可以拒绝；成功落地前再次检查双方存活、成年、羁绊、非近亲及状态。仅成功创建蛋后给母亲5年冷却，拒绝或条件失效不发蛋。

每颗半龙蛋保存准确生物父母及冻结的外观抽样。普通母亲提供1～2项，传说来源母亲3～4项且不超过母亲实际拥有的种类。每种只抽一次。孵化时从这颗蛋恢复父母，在当前持蛋人的角色作用域创建0岁正常人形后代，显式填写mother、father、real_father与`dynasty=inherit`，生物父母不随转手更换。父母死亡不主动抹掉其引用；引用缺失时不凭当前持蛋人猜测。

孵化前登记开始标记，创建成功后保存孩子引用、通知持有人并销毁这颗蛋；同蛋不能重复出生。非领主持有人也能孵化，但不执行无效的领主廷臣加入效果。半龙不进入原生飞龙全局列表，不成为坐骑，不获得永生／禁婚／禁育／禁继承标记；身体特质为寿命+150年、健康+2、勇武+3、外交+1。

### 兽栏与后续传说血脉

先对自有兽栏的成年母龙选择“指定繁育母龙”，再对同栏成年雄龙选择“强制繁殖”。界面显示已选母龙；确认后准确这对父母立即产1颗蛋，母龙1年冷却。实际执行再次核验兽栏持有人、建筑、同栏、年龄、性别、存活和非近亲。原有年度自动繁殖保留。

任一父母为传说或有明确传奇来源，每颗普通龙蛋在产下时独立以50%概率冻结传奇继承，雌雄仍各50%。孵化后的已驯服传奇龙采用“已驯服飞龙＋传奇血脉”，不叠加互斥的野生传说物种特质。普通双亲不产生传奇，不添加野外传说刷新。新半龙孵化仅在明确标记分支执行，普通MYV孵化的原逻辑保持在else内，并以原文快照验证完整有序保留。

### 自然出生血脉

半龙为代数0。它与人类的孩子开始，全部沿用原生怀孕／出生；`on_birth_child`从真实母亲和生物父`scope:real_father`取最近代数加1，四代逐步减弱，第5代不授予。没有合法来源不猜测，法律父／持蛋人／养父不会替代生物来源。

出生入口先检查真实双亲是否有半龙或四级血脉特质；普通人家庭不写入任何龙血变量、旗标或特质。独立负例预置普通新生儿的三类状态，实际执行解析后的出生入口并确认全部不变。

半龙记录母亲这条完整源龙的稳定人物引用。后续最近的一方传递来源，双方同等近则合并、去重，最多16条；trait说明显示对应源龙姓名。名称随同一人物改名更新，死亡或蛋转手不会变成另一个人物。四级互斥，不把血脉重置为半龙或永生。不追溯扫描和重写安装前所有既有家谱。
