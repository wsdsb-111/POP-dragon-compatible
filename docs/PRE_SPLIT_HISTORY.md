## 模块组包

新增“飞龙＋黑暗亲王”独立候选配置，保留原东方组合。组包、自动播放集检测及实机待验收范围见[兼容说明](docs/wyvern-pod-compatibility-20261102.md)。

运行Node.js 22或更新版本，无需安装依赖：

```powershell
node tests/run-tests.js
node scripts/build-package.js
```

默认把全部二十一个模块合并为一个完整包。1.3.9起，选择血统/龙王/升格模块时会自动带上配套地区文化和信仰定义，避免新生路径引用缺失；基础飞龙、俘获、化形和WoC独立组合保持。其他玩家可选已支持的组合：

```powershell
node scripts/build-package.js --modules=weight-of-crown
node scripts/build-package.js --modules=chinese-core,calendar-hud,palace-estate
node scripts/build-package.js --modules=wyvern
node scripts/build-package.js --modules=wyvern-votc-dialogue
node scripts/build-package.js --modules=wyvern-capture,wyvern-human-form
node scripts/build-package.js --modules=wyvern-kings
node scripts/build-package.js --modules=wyvern-ascension
```

| 模块 | 内容与依赖 |
|---|---|
| `chinese-core` | 东方王朝＋汉番礼制＋天家宗仪；保留原称谓／流官兼容，增加日历互斥和角色庄园入口 |

| `weight-of-crown` | 可独立组包，只要求Weight of Crown Fork |
| `wyvern` | 自动包含基础模块，适用于飞龙＋人格经验＋功绩显示这一已合并组合；不引入VOTC对话依赖 |
| `wyvern-capture` | 自动包含飞龙模块；增加猎杀战利品、俘获、喂养与驯服，不引入 VOTC |
| `wyvern-human-form` | 自动包含飞龙模块；增加成年羁绊飞龙可逆的人形肖像，不引入 VOTC |

构建器只复制所选模块并生成相应依赖，输出新的`.build/package-*`目录和逐文件SHA-256清单。不要把包含其他Mod引用的文件强行用于缺少依赖的组合，也不要只复制核心目录而漏掉所需合并模块。

## 安装与使用

关闭CK3后，将生成包中`mod/VOTC_Three_Mod_Character_Name_Compatibility`及相邻`.mod`安装到启动器实际使用的用户Mod目录，相邻描述符的path指向该目录。本机仍为`E:/Documents/Paradox Interactive/Crusader Kings III/mod`。补丁应排在所选模块涉及的上游Mod之后，只启用一份合并包。

地图界面右下角的WoC气候／人口按钮沿用`CanChangeMapMode`，可用于宫帐等当前政体；打开伯爵领或领地界面后显示对应WoC入口。人口模拟、税率和议会任务沿用上游；飞龙扩展规则以上述说明为准。固定龙王目录需要新开局，不在旧档改写人物性别、父母或已有事件。部分上游descriptor声明的是旧游戏范围，本补丁不修改上游版本声明来隐藏启动器警告。
