# CK3 西方龙头战利品材质优化施工文档

> **方案 A：灰橄榄绿 / 古铜褐龙皮（Olive-Brown Dragon Hide）**  
> **交付对象：Codex**  
> **改动性质：既有龙头宝物的贴图与材质升级，不修改宝物玩法逻辑**  
> **目标：把当前“浅黄石雕／木雕感”转换为“经过保存处理的真实西方巨龙头颅战利品”**

## 1. 项目背景与问题定义

龙头模型已经能够在《十字军之王 III》（CK3）宫廷中正常显示，目前摆放在石质陈列台上，几何形体和整体比例基本满意，无需重新建模。现有画面的问题主要集中于材质表现：

- 整体呈浅黄、沙金褐，暖色宫廷光照进一步强化了“石雕、木雕或陶塑”观感。
- 头顶、脸颊、颈部、角、棘刺和牙齿的颜色及材质区别不足。
- 鳞片与褶皱的层次感不够明确，缺少硬质鳞甲与皮革状软组织的区别。
- 此前试过的黑红配色又过于焦黑，像烧焦组织；**本次不得退回黑红／焦炭路线**。

### 1.1 叙事定位

这是一颗**击败巨龙后取下，并经过保存处理、长期陈列的真实龙头**，不是仿制雕像，不是金属铸件，也不是刚刚砍下的血腥尸块。需兼顾西方奇幻巨龙的生物感、贵族战利品的庄严感和 CK3 宫廷的历史氛围。

### 1.2 本次范围

**必须完成**：检查现有资产及贴图链路；分区重绘／调整 Base Color；建立鳞片、皱皮、角、牙齿、眼周的材质差异；在现有管线支持下调整粗糙度／高光／法线／AO；验证游戏内呈现。

**默认不修改**：龙头网格形状、UV 拓扑、模型缩放、底座、摆放坐标、宝物定义、游戏规则、事件脚本、原有资源加载链路。遇到确实需要改动的情况，先记录原因，只做最小必要修改。

## 2. 整体美术目标

关键词：`western dragon trophy head`、`aged reptilian hide`、`muted olive-brown scales`、`ancient green-bronze skin`、`dry preserved organic tissue`、`medieval royal court`。

实现原则：

1. **中等亮度、低饱和**。整体必须明显比此前的黑红方案明亮，但又不能变成均匀浅黄石雕。
2. **主体偏灰橄榄绿、古铜褐**，而不是鲜绿、亮绿、荧光绿。
3. **区域有层次**：厚硬头甲、面颊鳞片、喉部皱皮、干燥龙角、旧象牙牙齿分别呈现。
4. **旧化要克制**：微小磨损、斑驳、干燥、轻度失色；不增加鲜血、腐烂、黏液或发光眼。
5. **CK3 实机优先**：以游戏宫廷暖光下的最终观感，而非单纯 Blender 预览，作为验收依据。

## 3. 配色规范

以下 HEX 用作**贴图设计基准**，不是游戏内像素最终值。应结合现有贴图色彩空间、着色器及宫廷光照适度微调，不要求生硬地把每个像素改成纯色。

| 部位 | 建议颜色 | HEX | 使用说明 |
| --- | --- | --- | --- |
| 主鳞片（头顶、额骨） | 灰橄榄绿 | `#6E7558` | 主面积，保留纹理颗粒和不规则色差 |
| 次级鳞片（面颊、颈侧） | 深灰绿褐 | `#5A6047` | 主色向暗部的自然过渡 |
| 深层鳞缝、褶皱 | 深棕绿 | `#3E4335` | **仅用于缝隙、眼窝等局部**，不要大面积涂黑 |
| 鳞片边缘提亮 | 淡灰橄榄绿 | `#7A8161` | 轻微提升层级，不要形成金属镶边 |
| 下颌／喉部腹侧 | 浅灰褐／卡其灰 | `#8E836B` | 应明显有别于头顶硬鳞甲 |
| 喉部过渡阴影 | 灰褐 | `#6D6558` | 皱皮转折、颈纹阴面 |
| 喉部最深皱褶 | 深灰褐 | `#4A443C` | 仅用于深部组织遮蔽 |
| 角、棘刺根部 | 深角质褐 | `#4B4036` | 与皮肤显著区分 |
| 角、棘刺中段 | 灰褐 | `#665A4D` | 配合纵向纹理渐变 |
| 角尖（少量） | 骨灰 | `#A89C86` | 不要全部涂成骨白色 |
| 牙齿主体 | 旧象牙色 | `#D6C8A8` | 避免纯白 |
| 牙根、旧污 | 暗象牙褐 | `#A89A7A` | 少量，不做新鲜血污 |
| 嘴唇及口腔边缘 | 干燥灰肉褐 | `#7A675C` | 低饱和、不湿亮 |
| 眼窝阴影 | 深棕绿 | `#3E4335` | 烘托失去生气的眼部状态 |

**重要：** 可保留原有贴图的局部天然色彩和细微斑驳；上表表达的是区域的“色相／明度关系”，不是全部替换为平涂色块。

## 4. 各部位实施要求

### 4.1 头顶、额骨、正面大鳞片

- 主色 `#6E7558`；相邻大鳞片可在附近色域做小幅随机变化。
- 鳞甲边缘局部提亮至 `#7A8161`，缝隙下沉至 `#3E4335`。
- 硬鳞片表面保留相对紧实、略带角质反光的观感。
- **禁止**整片单一橄榄绿蒙版覆盖、明显金属化或把纹理磨平。

### 4.2 面颊、颈侧、面部褶皱

- 基底偏 `#5A6047`，向头顶主鳞片 `#6E7558` 平滑过渡。
- 深褶、鳞片交叠处有自然暗部，但不形成大面积黑斑。
- 相比头甲，突出细鳞、皱皮和干燥皮革组织感。

### 4.3 下颌、喉部和颈部腹侧

- 以 `#8E836B` 为主，褶皱过渡到 `#6D6558`，深处局部 `#4A443C`。
- 在相同照明条件下应比脸颊更浅、更偏灰褐。
- 保留肌理、皱褶与自然色差，不做成白骨、石膏或光滑布料。

### 4.4 龙角、颅侧棘刺

- 根部 `#4B4036`，中段 `#665A4D`，尖端**少量**过渡至 `#A89C86`。
- 使用不均匀、与角生长方向一致的纵向细纹，避免金属质感。
- 若现有角与皮肤共用贴图，应通过 UV 区域或明确材质掩码做区分；**不要依靠随意的全局颜色替换**。

### 4.5 牙齿、口缘

- 牙齿以旧象牙 `#D6C8A8` 为主，牙根少量过渡至 `#A89A7A`。
- 唇缘、口腔可见软组织采用干燥灰肉褐 `#7A675C`。
- 牙齿略平滑于龙角，但不能出现塑料高光或纯白色溢出。

### 4.6 眼睛、眼窝

- 压深眼窝，但保留轮廓以免变成大黑洞。
- 现有眼球可调整为浑浊灰黄／灰褐、失焦、低高光；如现有模型没有独立眼球，不要求添加新网格。
- 不得增加魔法发光、鲜艳虹膜或“活体眼神”。

## 5. 贴图与着色器实施

> **先审查当前 CK3 `.asset`、`.mesh`、贴图及材质槽的真实使用方式。** 以下 `roughness`、`specular`、`normal`、`AO` 都是视觉目标，不代表可以无条件直接新增任意 PBR 贴图；以本项目现有 CK3 着色器的通道定义和文件引用为准。

### 5.1 Base Color / Albedo（最高优先级）

- 优先在**现有 UV** 和已有颜色贴图上进行非破坏性调整。
- 通过区域掩码／UV 岛分组区分主鳞片、次级鳞片、腹侧、角、牙齿、眼窝。
- **保留原始纹理的形状、纹路、微表面信息**；使用色相校正、色彩混合、分区渐变，而非一键统一着色。
- 提高鳞片与缝隙的局部明度区分，但控制 AO 影响，避免缝隙黑成焦炭。
- 贴图不得含明显的固定方向灯光、过强烘焙高光或高饱和污渍。

### 5.2 粗糙度／高光

如现有 CK3 材质管线支持相应参数、通道或纹理：

| 区域 | 感知目标 | 参考 roughness 区间（仅适用于标准 roughness 定义） |
| --- | --- | --- |
| 大型角质鳞片 | 微弱硬质反光 | 0.50–0.65 |
| 面颊、颈侧皱皮 | 更干、更软 | 0.65–0.80 |
| 下颌、喉部 | 干燥皮革 | 0.68–0.82 |
| 角、棘刺 | 哑光角质与轻微纹理 | 0.65–0.85 |
| 牙齿 | 轻微瓷质／牙质光泽 | 0.40–0.60 |
| 鼻口及眼周少量区域 | 略微细腻，非湿亮 | 0.50–0.70 |

**注意：** 若 CK3 着色器采用 `smoothness`、`glossiness` 或打包通道，必须先确认其映射方式，不能将以上数值直接写入错误的贴图通道，也不能假定数值越大就一定越粗糙。

### 5.3 Normal / Height

在不改变模型几何的前提下：

- 保留现有大鳞片边缘和头骨结构法线。
- 有可编辑源图时，适度强化鳞片重叠、小鳞粒、喉部折痕、眼周纹路、龙角纵纹。
- 优先复用／修正现有法线；确有必要才从高度图烘焙或生成新法线。
- 控制强度，避免“石刻浮雕”“砂岩表面”或法线方向错误。
- 不得随意改变法线贴图的坐标约定（如绿色通道方向）。

### 5.4 AO / Cavity

重点区域：鳞缝、眼窝、鼻翼、嘴角、牙根、颈部层叠褶皱、角根连接处。

- 要增加细节的立体感，而不是大面积压黑。
- 若 AO 已烘焙在现有贴图或属于引擎光照贡献，避免重复叠加导致过暗。
- 保证中距离仍能读出形体结构。

## 6. CK3 实机适配要求

当前陈列环境为暖光、偏浅的石质底座和带纹饰的宫廷地面。此次优化必须解决以下两个相反问题：

1. 不能像此前黑红龙头一样因过暗而丢失纹理、显得烧焦。
2. 不能像当前浅黄龙头一样被暖光照成单色石雕。

建议以**实际游戏截图作为最终依据**，至少验证：

- 正面近景：脸、鳞甲、牙、角的分区清楚。
- 正面中景：龙头与底座分离清楚，仍能一眼辨识是有机龙皮。
- 侧面／斜侧视角：头甲与颈侧层次清楚，角根和棘刺不糊。
- 暖光较强区域：主色不漂成通体黄色；淡灰褐腹侧不变成石膏白。
- 偏暗区域：绿色不会直接变黑；鳞缝清楚但不发焦。

若整体太黄：优先微调 Albedo 色相及饱和度，**不要通过一味压暗来对抗暖光**。

## 7. Codex 实施步骤

### 第一步：盘点资产

1. 在项目中定位当前龙头 `.mesh`、`.asset`、所有关联纹理、可能存在的 `.blend`／源图及其引用关系。
2. 确认当前材质、UV、贴图通道定义及真实受支持的 Shader 属性。
3. 列明真正需要修改的文件，检查其许可证和使用范围；不修改无关宝物或其他角色材质。
4. 保留原文件或使用版本管理创建易回退的变更；不要盲目覆盖唯一的高质量源贴图。

### 第二步：完成颜色分区

1. 根据现有 UV 岛和纹理布局确定头顶、面颊、腹侧、角、牙、眼窝区域。
2. 按第 3、4 节配色调整 Base Color，保留原有鳞片纹理及自然变化。
3. 先导出**第一版仅 Base Color 改动**，检查颜色和细节是否符合目标。
4. 防止蒙版边界、接缝、贴图分辨率与色彩空间错误。

### 第三步：调整材质细节

1. 在现有材质系统允许的范围内增加区域间的光泽／粗糙度差异。
2. 检查法线贴图方向和强度；必要时优化角质、鳞片、喉部纹理。
3. 复查 AO 是否重复叠加导致局部焦黑。
4. 保存与 CK3 既有资源链路一致的贴图格式、路径及通道打包约定。

### 第四步：游戏内验证

1. 确认材质引用正常、贴图无丢失、无明显 UV 接缝。
2. 在此前提供的**相同宫廷环境和镜头距离**下截图对比。
3. 根据第 6 节和第 8 节验收标准做最小幅度修正。
4. 保留测试前后对比，以及变更说明，便于回退。

## 8. 验收标准

### 必须满足

- [ ] 龙头在 CK3 中正常加载；模型摆放、底座、尺度及宝物功能不回归。
- [ ] 主色明显转向**低饱和灰橄榄绿／古铜褐**，不再呈统一浅黄。
- [ ] 主鳞片、面颊、下颌、角、牙齿、眼部可以用肉眼辨别材质差异。
- [ ] 鳞片纹路及颈部褶皱在近景和中景下均可识别。
- [ ] 主体既不像烧焦黑红组织，也不像石雕／木雕／黄金铸件。
- [ ] 不出现鲜绿、荧光、过量湿亮高光或鲜血腐烂效果。
- [ ] 纹理、法线、颜色通道和 UV 正常；无明显压缩伪影或可见接缝。
- [ ] 在暖光和偏暗场景中均能看清龙头，不与石质底座混成一体。

### 若未达标，按以下顺序修正

1. **第一优先：** 主色偏黄／偏黑／分区不清。
2. **第二优先：** 角、牙、下颌仍像同一材质。
3. **第三优先：** 粗糙度、法线、AO 的细节层次。
4. **第四优先：** 小范围旧化、斑驳和细节美化。

## 9. 交付清单

Codex 最终需提供：

1. **改动文件清单**：包含具体路径、修改目的及相关贴图／材质的对应关系。
2. **修改后的可用资源**：符合现有 CK3 Mod 的文件组织和引用链路。
3. **简短变更说明**：颜色分区、材质改动、旧化处理、未修改的功能。
4. **验证报告**：实际完成的检查、实机结果；无法进行游戏内测试则明确说明，不得声称已通过。
5. **前后对比截图**（如果运行环境具备游戏截图能力）；否则标明建议测试的视角和场景。
