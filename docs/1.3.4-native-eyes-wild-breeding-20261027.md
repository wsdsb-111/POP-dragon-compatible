## 生育能力与金瞳

三种原生龙身体保留 `fertility=-1000`、`can_have_children=no`，用于禁止CK3的人类自然怀孕。当前主动人龙繁育、手动兽栏产蛋及兽栏年度自动产蛋都使用独立资格和蛋/人物创建，不查询自然生育力；人龙蛋保留5年冷却、手动兽栏成功产蛋保留1年冷却、年度兽栏仍每县10%。本版新增野蛋也走独立脚本。原字段不取消，以免恢复龙族人类婚孕/继承等未经要求的行为；身体说明增加对应提示。

此前金眼实现确实破坏了普通人的眼睛：真实 `database_conflicts.log:199` 显示 `eye_accessory` 被本补丁重定义，`error.log:29667` 等报告找不到 `normal_eyes`；29618–29621还报告自定义眼球贴图路径重复拼接。原始日志未复制进仓库。

现撤除自定义眼球基因、accessory、实体及生成器接入，退役旧 `mm_dragon_eyes_diffuse.dds`。角尾鳞保持。原生 `normal_eyes`、亚洲/暗虹膜/充血/盲眼等模板由原游戏和当前上游Mod提供。

人形仅用原生 `eye_color` DNA显示修饰，坐标(0.4,0.1)，覆盖普通/驯服龙、双生/合一/黑白皇、升格龙躯、初代/S/A/B/C/黑血及龙瞳特质。普通无血无龙瞳者不命中；龙形保留原眼球隐藏逻辑。原生调色板该点RGB(204,155,84)，当前51Mod实际启用的3436935316调色板为(229,196,100)，均为琥珀金；调色板本身不改。此修改不重写完整遗传DNA，也不声称改变原始遗传眼色。

龙形使用模型贴图，十二张原生/王权diffuse的琥珀眼区抽样6552像素与原绿色底图一致，均值RGB约(196.7,117.4,27.1)，未重绘龙形或改全局配色。抽样依据眼睑骨骼UV与琥珀色条件，并非完整虹膜的精确分割，不能替代实机观感。[眼色模块记录](1.3.4-eye-dna-module-20261027.md)。

## 普通龙差异

新局每条普通初始龙独立随机12–150岁、50%雌雄、体质、协调及性情，并独立抽取0.9/1.0/1.1成长系数。体长为 `5 + (原生年龄期望体长 - 5) × 原生体质成长系数 × 个体成长系数`，再按原生边界修正并刷新身份/战力；没有直接给战斗力或敏捷硬填随机值。具名十王族和其它原生创建器接口保持。四系各5–10、一次初始化、创造来源与初始种群保护继续保留。[差异化说明](1.3.4-seed-variety-20261027.md)。

## 野外繁殖最终规则

| 项目 | 实现 |
|---|---|
| 参与者 | 普通成年野龙，年龄≥12；排除龙王、固定王族、升格龙躯、已驯服、被捕/监禁或兽栏中的龙 |
| 饱食 | 双方 `myv_wyvern_hunger` ≥60（原生数值为饱食度） |
| 求偶 | 每年3–5月，雄龙在本县或邻县寻找合格雌龙，同可靠创造血脉优先，无同脉才回退 |
| 移动 | 在原生月度游荡之后实际移动到雌龙所在地；保持雄龙原巢穴，不永久搬巢 |
| 配对 | 必须已经同县，且非近亲/双生；雌龙从有效请求中同样优先同血脉 |
| 产蛋 | 每条成年母龙每年最多一次有效10%判定；成功一颗真实蛋，成功后5年野外冷却 |
| 等候 | 失败判定消耗本年机会，不加成功冷却；没有合格父龙不消耗机会；仍持有待孵野蛋时不重复产蛋 |
| 孵化 | 次年同月起自动尝试，幼龙0岁、未驯服，在母巢出生，记录真实母亲/父亲/real_father |
| 来源 | 先建立真实父母再登记来源，不使用先随机归属的普通创建器；传奇血脉蛋沿已有50%规则，不复制具名王位 |
| 上限 | 按普通非保护龙数量检查10/30/50/无限规则，王族/初始保护群不占普通配额；满额留蛋等候，不杀现有龙腾位置 |
| 转手 | 人类/独立受控角色取得野蛋后，停止野外自动孵化，沿用原库存/装备蛋规则；年度原生与延迟回调均重新检查 |

每月与每母年度均去重。龙王已有主动人龙/兽栏繁育保持，野外新门禁不改这些资格。原有每年20%随机补充成年野龙仍保留，与有父母的野外繁殖区分。

仍存在的蛋可保留已死父母引用；蛋若被引擎销毁，不凭空再造。母龙死亡时artifact继承/销毁顺序、真实地图移动和原生调度尚无实机验收。蛋由野龙持有是物品存储；出生地取记录的母巢。
