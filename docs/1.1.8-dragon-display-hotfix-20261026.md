# 1.1.8 龙首显示与品质背景修复（2026-10-26）

本版针对用户提供的1.1.7实机截图修复龙首过小、碎色遮盖雕刻细节，以及龙爪和龙角图标遮住品质背景的问题。图5左侧弯曲材料的现有类别为龙角，保留该类别、配方和视觉键。所有改动位于兼容Mod，原Workshop文件不修改。

## 龙首

完整头、颈和原基座保留，仍使用winner_77的CC BY 4.0授权模型。实际减面目标由240,000提高到400,000三角形，保留更多原高模形状；不是对旧网格空细分。等比缩放由0.36改为0.65，尺寸约为旧版的1.81倍，包围盒约50.6宽、65高、48.8深，底面仍在Y=0。五个原生mesh子节点，每个不超过60,000顶点，统一计算切线后分件。

4K颜色／法线／属性贴图及完整13级mip保持。原鳞片颜色采样叠加了与雕刻不一致的密集碎纹，远景缩小时显得糊且偏金。本版压低该纹样强度，按头颈／侧面／后侧连续分区；角、牙、软组织仍分别使用黑褐、旧骨色和灰粉色，鳞片凹缝由几何细节加强。角根过渡改为平滑遮罩，避免坐标阈值形成整齐的水平色带。法线B通道为0，不恢复自发光。

[正面预览](../artwork/wyvern-trophies/models/head-front.png)、[侧面预览](../artwork/wyvern-trophies/models/head-profile.png)与[源数据](../artwork/wyvern-trophies/models/winner77-head-source.json)使用本版实际网格和材质。离线预览自动适配画面，因此尺寸变化以包围盒和游戏中固定展台为准；这些图不是CK3实机截图。

## 品质背景

原图标是240×240全不透明方图，其紫色布底遮住了`window_inventory.gui`的原生`artifact_bg.dds`及`Artifact.GetIconFrame`品质层。本版通过内置image_gen提取透明的龙爪、龙角，再由构建脚本保留alpha编码到DXT5；背景由实际品质决定，未把所有物品强行画成卓越。图标名与宝物视觉键不变，已有物品也可直接显示。
