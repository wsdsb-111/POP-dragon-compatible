- 蛰眠特质参照本机POD的失能/禁止生育/继承/指挥机制。猎杀/野龙判定、骑乘/骑士、化形、手动/自动繁育均显式排除；原月度维护跳过蛰眠，停止饥饿和游荡；每日伤势恢复仍继续。
- 六项决议在执行支付前再次验证同一目标存活、蛰眠、玩家状态、羁绊、各王座和资金。白皇每系须双生子均存活苏醒或已合一；黑皇还须白皇苏醒、四系合一、羁绊至少一位存活合一君主。唤醒移除蛰眠，不重造人物、不自动驯服。
- 吞噬交互要求同座互相引用、可见双生关系、两位苏醒且均羁绊玩家，并以全局王座标记限制一次。记录被吞噬者真实引用，实际死亡，幸存者保持ID与性别，替换王权并改合一名/称号。界面明确永久死亡。
- 王权战力通过原MYV唯一刷新链写回真实勇武：220/350/450/600阶梯上限，在完整力量封顶之后作用伤势、饥饿和营养不良。驯服只换原生身体身份，不移除王权；龙蛋只有原50%传奇来源继承，不继承王权。
- 四个原MYV伤口入口各包装一次70/30判定。完全挡住时不写伤口，也不计徒步有效伤害命中；正常分支调用完整原生别名，保留部位选择和清理。没有全局减伤乘数，没有调用方和后端双抽。
- 每位存活王族有带去重标记的延迟一天事件，复用原生恢复/迁移/伤势清理；王族退出月恢复。普通龙保持每月每受伤部位-1。不是扫描人口的全局每日事件。
- 王权支援解析独立龙骑士或实际骑手所在军队的指挥官，同军只取最高阶，最多2天过期。个人王权属性与指挥官支援分开；不增加第二份原生坐骑体型优势。
