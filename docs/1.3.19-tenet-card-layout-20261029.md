# 1.3.19 核心信条卡片排版修复

用户提供六派实机截图及官方卡片对照：1.3.18自定义插画已能加载，但标题偏左、底条延伸，部分插画靠上或超出卡框。此前通过的静态资源校验未覆盖这些真实UI布局问题；本版据截图修复，不将旧静态PASS视为实机布局正确的证据。

## 标题位置

原标签继承 `text_single` 的自动尺寸，以及 `text_label_center` 的左右40像素背景边距；仅指定居中和最大宽度没有保证其最终落在牌面中心。新增龙之信条专用的直接子文本框，父/子均显式锚定底部水平中心，偏移 `{0 -10}`，尺寸118×32，字号18、最小12，允许换行但关闭自动宽度。标题文本、直立字体及提示行为保持；不继承会延伸的标题背景。

显示条件使用现有 `mm_v1314_is_creed_view` 与当前 `Faith.MakeScope`，只为共享龙之信条显示固定标题。普通宗教保留原标签vbox及其字号、文字和布局，两个分支互斥。

## 插画范围

实机与像素检查显示，旧内容按252×280、源Y=16排布，叠加原生控件Y=-10后，最高的天空图会到卡片Y=-2；左右约X=2—128，而原生牌框约在X=6—124。新的布局保持原生130×200控件、Y=-10及260×400透明DDS画布，只重排18张自定义插画。

新源图安全区为 `{30,108,200,224}`，等比完整容纳主体，空白按区域中心均分。换算为实际卡片，内容落在X=15—115、Y=44—156，中心为 `{65,100}`；标题框位于X=6—124、Y=158—190。源图Y≥336保留透明，用于避免叠加偏移后侵入标题。横向原稿保持横向比例，不为了填满竖牌面拉伸或裁主体。

原始与已批准处理稿均不重绘。6张特殊教义DDS、图像引用、宗教机制、美德罪恶、姓名和家谱规则保持。
