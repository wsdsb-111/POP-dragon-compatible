# 1.3.2 血脉实施记录（2026-10-27，待集成验证）

本记录对应 [血脉设计](1.3.2-lineage-design-20261027.md) 和 root 后续授权。仅编辑独立兼容仓库；原游戏/MYV/父 VOTC 未写入，既有未提交改动未还原。版本、sources、组包、runner、独立 QA 与安装由 root 统一处理。

## 已实现

- 保留初代/S/A/B/C/黑血旧 trait 键及原寿命、健康、抗疫表。黑血个人军事/勇武为 40/80，月威望 12、月正统度 2.5、住所收入 25%；黑血和 S/A/B/C 无将领字段。六来源分支按设计的小属性表，可并存。
- 生物祖源完整变量列表去重并集，无 16 条截断；旧 16 槽只用于兼容显示，显示总数。旧 slot-only 记录先非破坏纳入列表；count 缺失时重建投影。吸收来源单独列表/计数/显示/能力标识，不写生物祖源，不自动遗传。
- 自然出生使用母亲/`real_father`，一次性初始化先落地。等级与所有合法来源独立计算；任一可遗传混血亲本合计只抽一次 10%，黑血终端。无来源的旧混血仍可按用户规则生育/突变，缺失祖源不猜。
- 人龙蛋使用真实性别母父、人类/真龙分角色引用。具名王族本人直接子女初代，普通龙（包括传奇后代）直接子女 S；王位和真正龙身份优先于残留混血 tier。新蛋在创建时冻结出生等级与一次突变（0 初代、1 S、6 黑血），孵化不重抽；旧无冻结字段的蛋保留原初代语义。
- 同一繁育 interaction 支持人类或真正龙族提出，另一方原生同意；任意成年异性人类无需沐血，保留羁绊、人形、非近亲、非囚禁失能及五年冷却，接受时重检。侵蚀接位玩家可以从龙族一方主动提出；仅融合借形者不能占用真龙亲本位置。蛋由提出者保管，亲缘/血脉/文化/信仰均不取自持有人。正常已有王朝继承保留，仅 lowborn 才回退人类亲本 house 或创建王朝。
- 新局 pending + after_lobby 同步一次初始化，五组各最多 5 个真实独立王朝，每组一位 S 族长、其余四位 A，真实子女分别 A/B。只按当前伯爵领文化筛选，随机无放回轮次平均分配余数；白五、黑零、零有效文化则零，旧档/后续年份不补造。不改现有地图人物或文化。
- 独立死亡吸收：原生真龙猎杀 `death_myv_wyvern_slain`；高阶混血使用真实原生致死单挑 `FATALITY=always`。`on_death` 检查真实 `scope:killer`，混血决斗还要求精确双向 hunt 绑定及 `death_duel`，先 victim claimed，再发分。门槛 12/30/60，猎物 1..6，单 if/else_if 每次最多一级，初代不可升级取得，黑血不变为可遗传等级。
- 原生已核实结果 scope 为 `sc_victor/sc_loser`，原生死亡 `killer=sc_victor` 在输出回调前发生。输出/失效回调仅清理精确旧配对，不能重复死亡/发分，不能清掉另一场较新猎杀。

## 跨模块 API

| API | 调用 scope / 参数 | 行为 |
|---|---|---|
| `mm_dragon_append_biological_origin_effect` | SOURCE 角色；`CHILD = <角色>` | 非破坏追加确切生物源龙并登记可遗传分支 |
| `mm_dragon_append_absorbed_origin_effect` | SOURCE 角色；`TARGET = <角色>` | 非破坏追加获得来源/分支，不改生物祖源 |
| `mm_dragon_refresh_branch_traits_effect` | TARGET 角色；`yes` | 根据分别保存的 bio/absorbed 标识显示能力 |
| `mm_dragon_copy_biological_origins_effect` | PARENT 角色；`CHILD = <角色>` | 完整生物来源并集，兼容旧槽，不读取 acquired |
| `mm_dragon_register_true_dragon_origins_effect` | 真龙角色；`yes` | 先 source hook，再登记自身及真实龙亲本来源；可重复 |
| `mm_dragon_creation_source_hook_effect` | 真龙角色；`yes` | bloodline 默认空，kings 后加载接创造归属 |
| `mm_dragon_is_true_dragon_parent_trigger` | 角色；`yes/no` | 原生三龙 trait 或真正王位；不看 portrait/body |
| `mm_dragon_is_royal_parent_trigger` | 角色；`yes/no` | bloodline 默认 false，kings 后加载四王位 trait |
| `mm_dragon_is_independent_royal_parent_trigger` | 角色；`yes/no` | 默认 false；仅自主侵蚀接位者由 ascension 后加载授权，可用配偶/情人/灵魂伴侣作为羁绊 |

源 API 位于 `patches/wyvern-bloodline/mod/common/scripted_effects/mm_dragon_lineage.txt`。融合模块获取龙血调用 absorbed API；侵蚀结局真实王位可以成为初代亲本，仅融合借形不行。`mm_dragon_has_inheritable_blood_trigger` 先排除真龙，再看初代..C，防止新王保留旧 tier 影响正常纯龙繁育。

## 文件及集成

新增/修改范围为 bloodline 模块玩法、本地化与两份 kings 后加载兼容文件：

- `common/scripted_triggers/zzzzzzzzzz_mm_lineage_breeding_compat.txt`：覆写三项繁育别名，复用 bloodline base；王位/创造分支接口只在 kings 内引用它自己的 trait。
- `common/scripted_effects/zzzzzzzzzz_mm_lineage_initialization_compat.txt`：五组确切文化/具名源龙目录，沿用王族 bootstrap。

bloodline 基础不引用 royal/ascension 未知 trait，可独立于两模块。新原生蛋孵化在父母落地后登记真龙来源。root 负责删除 kings 中遮蔽它的旧完整 hatch 覆写、后加载 source hook 接 `mm_royal_assign_creation_effect`、wild 创建接真龙登记。existing kings identity/8z trigger 文件不在本代理改动范围。

`on_game_start_after_lobby` 的来源兼容只遍历 MYV 龙注册表，既不扫描全部人物也不生成家族。没有年度/每月混血家族生成器。

## 验证证据与限制

本代理只做静态检查：22 份模块 PDX 文件括号/引号平衡；英/简中 UTF-8 BOM、键唯一及引号形式正确；六级寿命/健康/抗疫逐字段与原表一致，黑血 40/80 且黑血与 S/A/B/C 无将领字段。未跑 Node 或启动 CK3，这些检查不代表 PDX 引擎执行或实机 PASS。

独立 QA 由其他代理编写对抗 fixtures 后交 root 单进程运行。真实 CK3 仍需确认新局退出大厅时点、文化实际数量、王朝/入廷、双方提出时的真实母父与蛋归属、旧档/旧蛋、借形与真王位区分、单挑胜负/失效/死亡及来源 UI。尚无这些实机验收结果，不能称完全验收或发布冻结。

## 自主王族生育收尾

自主侵蚀接位者不是原生宠物，不能要求不存在的驯养羁绊链。人龙基础配对现保留原生 MYV 羁绊，另仅对 `independent_royal=true` 且实际王位有效者，允许人类配偶、情人或灵魂伴侣作为羁绊；成年、异性、人形、非近亲、同意、非囚禁失能与冷却全部继续复核。默认接口 false，不放宽普通龙；只有融合借形的人类没有此豁免。具体自主身份由 ascension 后加载核验真实身体、侵蚀胜出状态和当前王位。

自然生育的真实母父 genesis 已有实现并接入 `on_birth_child`：恰一方真龙、一方人类时，王族直接子女初代、普通龙直接子女 S，追加实际龙亲本与两边合法生物来源；人类亲本为初代..C 才有一次 10% 黑血，否则不抽。只融合借形的人类不能成为新龙源。收尾进一步让每个常规混血亲本候选先满足 `has_inheritable_blood`，避免真龙保留旧 mixed tier 被再次当作混血来源处理。没有重写已有角色、旧蛋或出生旗标。

独立 QA 补自主王族三种关系、普通龙不可绕过、新王/普通龙双向自然生育及借形排除 fixture；此处未运行 Node，结果仍由 root 串行执行后登记。
