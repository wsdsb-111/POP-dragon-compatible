# CK3 龙族系统后续施工任务书

## 一、执行顺序与项目边界

前置任务是完成此前安排的飞龙 Mod 模型资源审查，输出模型结构、骨骼、材质、贴图及动画依赖报告。

完成前置任务后，继续执行以下三个模块，不要只停留在方案设计阶段。

**首先确认项目边界：** 检查当前工作区是否同时包含飞龙模型、四大龙王、黑皇、白皇以及龙族血脉系统。如果这些内容分属不同 Mod 或仓库，不得将不相关的功能混入 `CK3 Mythical Vanilla : Wyvern`。应先报告项目归属，再在正确的项目中实施对应任务。

所有改动均应保留原始资源和可回滚版本。优先复用现有代码、特质、事件、决策及资源系统，避免重复实现已有功能。

---

## 二、任务一：优化四大龙王、黑皇与白皇的模型配色

### 2.1 目标

在暂时不具备独立制作高精度模型的条件下，先通过材质和颜色调整，提高六位龙族核心角色的视觉辨识度与整体质量。

本阶段只修改模型颜色、材质及必要的贴图，不重新建模，不替换模型，不修改游戏玩法。

优化对象包括：

- 青铜与火之王
- 海洋与水之王
- 天空与风之王
- 大地与山之王
- 黑皇
- 白皇

### 2.2 配色方向

请根据每位角色的权能、身份及现有模型结构，分别设计适配 CK3 宫廷环境的配色。

建议采用以下方向作为初始参考：

| 角色 | 推荐配色方向 | 视觉特征 |
|---|---|---|
| 青铜与火之王 | 暗青铜、铁灰、克制的熔火红 | 古老、威严、具有金属与火焰特征 |
| 海洋与水之王 | 深海蓝、灰蓝、低饱和青绿 | 深邃、冷峻、具有水生生物质感 |
| 天空与风之王 | 蓝灰、银灰、冷白 | 轻盈、锐利、具有天空与风暴特征 |
| 大地与山之王 | 灰橄榄绿、岩褐、石灰色 | 厚重、坚固、具有大地与岩层特征 |
| 黑皇 | 黑曜石色、深灰、少量暗紫或暗红 | 深沉、压迫感强、具有独特的黑皇辨识度 |
| 白皇 | 象牙白、冷白、克制的浅金色 | 高贵、纯净、与黑皇形成鲜明对照 |

以上仅为配色方向，不要求将所有模型统一成单一纯色。

### 2.3 实施要求

1. 先检查每个模型实际使用的材质、贴图、UV 和资源引用。
2. 优先修改现有贴图和材质，不要无必要地重建模型。
3. 根据模型结构区分鳞片、腹侧、角、棘刺、翼膜等不同区域。
4. 保持低饱和、自然、有层次的视觉效果，避免高饱和纯色、塑料感和过度发光。
5. 配色应适配 CK3 实际光照，而不是只在外部贴图预览中好看。
6. 不得破坏模型原有的骨骼、动画、UV 或其他依赖。

### 2.4 验收标准

- 六位角色具有清晰且互不混淆的配色。
- 颜色能够体现各自的权能与身份。
- 鳞片和角质等材质具有合理层次。
- CK3 实机显示正常，没有明显偏色、贴图丢失或材质异常。

## 三、任务二：重构龙族血脉体系

### 3.1 核心设计

将当前龙族血脉体系划分为不同的血脉分支。

不同祖先的血脉应具有不同的属性加成、负面效果或特殊能力，不能让所有混血种都使用完全相同的血脉效果。

默认的五个血脉源头为：

- 青铜与火之王
- 海洋与水之王
- 天空与风之王
- 大地与山之王
- 白皇

黑皇不参与默认的初始混血家族生成，但必须保留独立的繁育分支：如果黑皇通过游戏机制繁育后代，应允许产生黑皇来源的特殊血脉，并明确记录其祖源。

### 3.2 血脉对应文化

请按以下映射建立候选文化池。实际实施前必须检查游戏和 Mod 中的文化 ID，不能直接假设中文名称或显示名称就是代码中的文化键。

| 血脉源头 | 候选文化 |
|---|---|
| 青铜与火之王 | 汉、波斯 |
| 海洋与水之王 | 希腊、意大利、撒丁、山南、罗马 |
| 天空与风之王 | 诺斯、诺曼、挪威、瑞典、丹麦 |
| 大地与山之王 | 埃及、马什里克、贝都因 |
| 白皇 | 大和 |

### 3.3 开局混血家族生成规则

四大龙王各自拥有五个初始混血家族名额。请在新游戏开局初始化阶段，按照对应文化池分配这些名额。

具体规则如下：

1. 先检查当前开局地图中的文化分布。
2. 如果某种候选文化在地图上没有任何伯爵领使用，则视为该文化在当前开局已经消亡，不得将其纳入候选池。
3. 只从当前地图中实际存在的候选文化中随机分配家族。
4. 五个家族名额应尽量均匀地分配给所有有效文化：
   - 有五种有效文化时，每种文化分配一个家族。
   - 只有两种有效文化时，按 3:2 分配。
   - 有三种或四种有效文化时，尽可能均匀分配。
   - 只有一种有效文化时，五个名额均分配给该文化。
5. 不得因为候选文化已经消亡而强制复活该文化，或将家族分配给不存在的文化。

**开局初始化限制：**

- 上述五家族数量限制只针对新游戏的初始状态。
- 每位龙王对应的五个初始混血家族中，开局只能有一位族长达到 S 级，其余族长最高为 A 级。
- 游戏开始后，不再限制混血家族的新增数量，也不再强制限制血脉等级的正常提升。
- 初始化逻辑必须只执行一次，不能在每年触发的事件中反复重置家族或血脉等级。

白皇明确使用大和文化，但原设计尚未明确其是否也采用四大龙王的五家族规则。请先检查现有设计；如果没有既定规则，在实现白皇的初始家族生成前向我确认，不得自行扩展。

由于 CK3 的初始化时机存在引擎限制，请使用实际可行的开局初始化机制，并确保玩家首次进行正常操作时，初始家族和等级已经正确生成。

### 3.4 血脉祖源标识

所有龙族及混血种都必须明确显示自己的血脉来源。

具体要求：

1. 每个血脉分支都应关联对应的龙王或白皇。
2. 角色界面或血脉特质说明中，必须明确显示其祖源。
3. 后代继承血脉时，不得因为家族变更、文化转换或其他普通角色操作而丢失祖源信息。
4. 如果角色同时继承了多个血脉来源，应设计能够保留这些来源信息的机制，不得随意覆盖。
5. 不同祖源应对应不同的属性加成与特殊效果。

请先检查现有特质与修正项，整理出各血脉分支的效果表，再实施修改。

### 3.5 通过猎杀提升血脉等级

加入血脉吸收机制，使低等级混血种能够通过猎杀高级混血种来提升自身血脉等级。

规则如下：

- 猎杀高级混血种后，允许通过吸收对方血脉提升自身等级。
- 血脉等级越高，继续提升所需要的血脉吸收量越大。
- 玩家也可以通过猎杀真正的龙族获取血脉提升。
- 升级门槛应随等级递增，避免低等级角色通过少量猎杀就直接达到最高等级。
- 应沿用现有血脉等级系统和角色死亡机制，避免重复创建相互冲突的升级逻辑。

具体数值请结合现有等级体系设计，并集中配置，便于后续调整。

## 四、任务三：重构「沐浴龙血」为龙血僭主与融合系统

### 4.1 特质重构

将现有的「沐浴龙血」机制重构为两个阶段。

**第一阶段：王座僭主之血**

这是角色获得龙王之血后、尚未彻底融合时的初始状态。

要求：

- 保留现有的龙血获取入口，但将初始特质改为「王座僭主之血」。
- 其正面能力应显著弱于当前「沐浴龙血」的效果。
- 必须加入两个负面效果：「龙化侵蚀」和「王座低语」。
- 角色必须通过后续仪式彻底融合龙血，才能获得原有「沐浴龙血」的正面能力。

**第二阶段：王座执掌之血**

当角色成功完成龙血融合后，将「王座僭主之血」升级为「王座执掌之血」。

要求：

- 正面效果恢复到当前「沐浴龙血」的能力水平。
- 明确显示该血脉来自哪一位龙王。
- 成功融合后，解除僭主阶段的龙化侵蚀和王座低语负面效果，并停止对应的侵蚀机制。
- 不得让同一角色同时保留相互冲突的初始特质与融合后特质。

### 4.2 负面效果一：龙化侵蚀

「龙化侵蚀」表现为角色的身体逐渐向龙类畸变，对应龙族设定中的死侍化现象。

影响方向包括：

- 外交能力下降。
- 健康受到负面影响。
- 社交能力或相关角色互动受到影响。
- 其他角色对其好感度下降。

请结合 CK3 现有属性、修正项与事件系统实现，并保证效果会随着龙血侵蚀的发展逐渐显现，而不是仅有一段描述文字。

### 4.3 负面效果二：王座低语

「王座低语」表现为角色持续听到残留在龙血中的龙王意识回响。

对应效果包括：

- 触发与疯狂相关的事件。
- 触发偏执相关的事件。
- 增加压力，必要时引发进一步的负面后果。
- 事件内容应体现角色正在受到龙王残留意志的侵蚀。

应结合现有事件与压力系统实现，避免事件完全随机、毫无反馈，或以过高频率触发导致游戏体验失衡。

### 4.4 双进度条机制

为「王座僭主之血」建立两个相互竞争的进度条。

#### 进度条 A：龙血侵蚀

- 每年自动增加。
- 表示龙血对角色身体、精神与人格的侵蚀程度。
- 如果侵蚀进度首先达到上限，角色将彻底龙化，成为新的龙王，并继承其所猎杀龙王的名字。
- 该结局应通过实际游戏机制执行，不能只在事件描述中宣布角色变成龙王。

#### 进度条 B：龙血融合仪式

- 角色可以通过举行仪式压制并融合体内的龙王之血。
- 每名角色每年最多举行一次仪式。
- 仪式可以要求前往指定圣地、消耗虔诚、金钱、威望等资源，或组合使用地点和资源条件。
- 每次成功举行仪式，都会推进融合进度。
- 当融合进度达到上限时，立即将「王座僭主之血」升级为「王座执掌之血」，恢复原有「沐浴龙血」的正面效果，并终止龙化侵蚀结局。

两条进度条的结算必须明确：如果龙血侵蚀先达到上限，角色立即龙化；如果融合仪式先达到上限，角色完成融合。不得在同一结算周期内让两种结局同时发生。

### 4.5 龙王继承与祖源记录

如果角色的龙血侵蚀进度达到上限：

1. 角色彻底龙化，成为新的龙王。
2. 继承其所猎杀龙王的名字。
3. 保留并正确记录对应的血脉来源。
4. 更新其龙王身份及相关角色状态。
5. 不得因为转化为新龙王而丢失原有血脉数据，或破坏其他血脉分支的继承逻辑。

请优先复用现有龙王身份、死亡、继承与血脉记录机制。如果当前 Mod 尚无完整的龙王继承实现，应先提出具体方案并说明需要新增的角色状态。

## 五、开发约束与验收标准

### 5.1 开发约束

1. 先审查现有实现，再进行增量修改。
2. 模型配色、血脉系统和龙血特质分阶段提交、分别测试。
3. 保留原始文件及回滚方案。
4. 不随意删除现有特质、事件、决策、角色变量或模型资源。
5. 对旧存档进行兼容性检查，尤其是已有「沐浴龙血」角色和已经生成的混血家族。
6. 不得只修改本地化文本而不实现对应的游戏机制。
7. 对于 CK3 引擎无法直接支持的 UI 或进度条表现，应先验证可行性，并采用项目现有的可行方案，不能声称未实现的功能已经完成。

### 5.2 验收标准

**模型配色**

- 六位核心角色的配色明确区分。
- 游戏内材质、贴图和动画正常。

**血脉体系**

- 各龙王的文化映射正确。
- 已消亡文化不会参与开局家族分配。
- 开局家族分布和 S/A 等级限制正确。
- 游戏开始后，血脉新增和等级提升不受开局限制。
- 每个角色均能显示对应的血脉来源。
- 猎杀吸收机制能够正常提升血脉等级。
- 黑皇的特殊繁育分支能够保留并正确生成后代血脉。

**龙血特质**

- 初始特质正面能力显著弱于原「沐浴龙血」。
- 龙化侵蚀和王座低语能够正常触发。
- 每年最多举行一次融合仪式。
- 侵蚀进度先满时，角色会成为新的龙王并继承对应名字。
- 融合进度先满时，角色升级为「王座执掌之血」，恢复原有正面效果并解除对应负面状态。
- 两条进度条不会同时触发互相冲突的结局。

完成后请分别输出模型配色修改记录、血脉系统实现记录、龙血特质实现记录、测试结果及尚未解决的问题。
