# 1.3.2 模型配色实施记录（2026-10-27）

本阶段已制作六张独立albedo并接通角色外观定义；**未运行CK3，宫廷光照、动画、旧档和切形实机验收仍待验证。** 前置结构审查见[资源审查](1.3.2-model-resource-audit-20261027.md)。Node专项和集成测试由root/独立QA串行执行，本记录不代替其实际结果。

## 配色与资源不变量

用户允许脚本精确配色后，使用原MYV atlas同坐标像素作确定性RGB变换；未采用六张ImageGen重绘稿。火系暗青铜/铁灰与暗熔红膜，地系灰橄榄/岩褐/石灰，海系深海蓝/灰蓝/低饱和青绿，天系蓝灰/银灰/冷白，黑皇黑曜灰/少量暗紫，白皇象牙白/冷灰/克制浅金。原鳞片及角质细节、暗缝保持，眼/口地标原RGB保留。

六DDS路径为`patches/wyvern-kings/mod/gfx/models/portraits/myv_wyvern/mm_royal_{fire,earth,sea,sky,white,black}_diffuse.dds`。每张2048×2048、16,777,344字节；沿原未压缩DDS格式及原alpha，不新增mip或改变normal/properties。全部模型/骨骼/蒙皮/UV/动画/shader复用原文件，不重新导出。普通六色贴图、原Workshop及战利品未修改。

实际区域依据为原三角面UV、主骨权重分类、原色变体差分和原图HSV地标；不是任意UV矩形。原UV骨分类不能冒称精准解剖材质mask，浅色区域包含腹侧和浅角质。完整配方、mask、限制及源指纹见[配色源说明](../artwork/dragon-kings/palettes-v132/README.md)和`artwork/dragon-kings/palettes-v132/manifest.json`。

## 接线与模块边界

`wyvern-kings`新增独立`mm_royal_wyvern.asset`、accessories、六个原gene的追加模板和portrait路由。原gene的模板/indices保留，只在末尾增加独立模板。正常、飞行、奔跑、野外空战、骑乘、compact和纪念头像均有royal分支；每系11档size保持原scale。骑乘从`var:myv_riding_portrait_wyvern`目标选色，保留骑手的真实外观/姿态，不能看骑手是否royal。compact继续用原无骨compact mesh；它不是宫廷龙首战利品。

正常body模板为`mm_royal_{family}_{hatchling|tier_01..10}`；其他姿态模板为`mm_royal_{flying|running|mounted|wild_aerial}_{family}_{size}`；compact为`mm_royal_compact_{family}`。game层priority1300，显式pose层1400，现有人形priority2000保持。

公共视觉接口`mm_royal_visual_{fire,earth,sea,sky,white,black}`在kings默认只识别实际王权trait和王座；不会因普通传奇血统、祖源或创造归属命中。`wyvern-ascension`后加载同名接口扩展，合法条件为`mm_asc_dragon_body`、当前`mm_asc_dragon_form`及真实血源快照`mm_asc_visual_family`（1火/2地/3海/4天/5白/6黑），并排除`mm_wyvern_human_form`。新body的source family优先于旧royal throne残留；family0完整沿原色模板。源size/color由玩法模块快照/刷新，本配色生成器不改玩法效果、身份初始化或血脉结算。

asc专属trait桥、无人体附件层、family0显式pose和priority2200人形恢复层都位于asc模块，避免kings反向依赖asc。新body龙形使用原no_portrait morph与龙身体附件，人形恢复normal_portrait并清空完整/飞行/奔跑/骑乘/空战/compact龙附件。没有重复定义gene。
