# 1.3.4 原生眼色修复模块

## 实机根因和修复

用户提供的真实 CK3 日志显示：`database_conflicts.log:199` 报告 `common/genes/mm_dragon_decor.txt:33` 覆盖 `eye_accessory`；`error.log:29667` 等报告 `Unknown eye_accessory gene accessory group normal_eyes`，对应普通人眼模板被覆盖。`error.log:29618–29621` 另显示自定义眼球 diffuse 的目录和完整路径被拼接两次，贴图找不到。原生 `game/common/genes/02_genes_accessories_misc.txt` 的该基因包括 `no_eyes`、`normal_eyes`、`normal_eyes_no_shadow`、`normal_eyes_dark_iris`、`normal_eyes_asian`、`bloodshot_eyes`、`blind_eyes`；补丁独立重定义只含 index 240。日志证明覆盖和贴图缺失，不单是 alpha 或虹膜颜色问题。

移除了独立 eye_accessory 定义、自定义男女眼球 accessory 与 meshsettings/entity，生成脚本也不再生产或接入自定义眼球。原专用于龙形的 no_eyes 保持。剩余 decor genes 文件使用 UTF-8 BOM。角、尾、鳞保留。

原 `mm_dragon_pupils` 与初代/血脉 1–4/黑血采用 `dna_modifiers = { color = { mode = replace gene = eye_color x = 0.4 y = 0.1 } }`，额外显式排除 `mm_asc_dragon_form`，原 MYV 龙形仍按既有条件排除，已切换人形才允许。普通人不命中条件。该 modifier 改显示颜色，不声称永久写入或继承 DNA，也不改眼睛网格、模板、贴图。原生 `00_genes_color.txt` 定义 eye_color；已安装 Workshop `3755292370/gfx/portraits/portrait_modifiers/00_dominant_genes_overrides.txt` 使用同一 `color`/`mode = replace` API。游戏自带 `00_trait_modifiers.txt` 亦有 eye_color `mode = modify`。坐标从原生 `game/gfx/portraits/eye_palette.dds` 的 256×256 图像采样：归一化 (0.4, 0.1) 近像素 (102,26)，RGB (204,155,84)，为琥珀金；实际渲染、坐标方向和观感需 CK3 实测，未改原调色板。

旧版 `mm_dragon_eyes_diffuse.dds` 已无运行时引用，但资产文件和 sources 清单原封保留供打包负责人清理；升级包必须覆盖已修改的 genes/accessories/asset/modifier，并从安装输出移除旧自定义眼球 DDS（确保按已知目标路径清理）；不能只做增量复制留存旧版 `.asset`。其他原生眼球模板和龙形 suppression 不应清理。

## 静态验证与限制

Python 小检查通过：genes BOM、括号配对、两处颜色替换、龙形排除、被停用的自定义眼球链接与生成脚本语法。未启动 CK3、未执行 Node 或完整打包；普通人眼球恢复、游戏中受影响人形颜色与龙形未变化仍待实机验收。

## 全龙族金眼追加范围

新增人形 modifier：human-form 的 `mm_wyvern_human_golden_eyes` 覆盖原生普通/驯服/传奇三 trait；kings 的 `mm_royal_human_golden_eyes.txt` 覆盖龙王、合一、白王、黑王四 trait；ascension 的 `mm_asc_human_golden_eyes.txt` 覆盖 `mm_asc_dragon_body`（融合和侵蚀），均要求 `mm_wyvern_human_form` 并排除 `mm_asc_dragon_form`。六血脉等级和 pupils 继续使用各自 modifier；基础模块不引用可选模块特质。Python 静态检查覆盖 trait、flag、color 和括号；新文件需纳入发行清单。

龙形只读纹理检查：`scripts/build-royal-palettes.py` 使用原绿龙贴图的 HSV 眼/口保护并还原 RGB。以 eye_face 骨骼 UV 区与 amber HSV 阈值求交，得到 6552 个像素，bbox (555,678)–(670,796)，六张 MYV 原始色（red/green/black/grey/gold/nightmare）和六张 royal 色（fire/earth/sea/sky/white/black）在这些像素全部与绿龙源图相同，平均 RGB (196.7,117.4,27.1)，显示琥珀色。骨骼分区不是精确虹膜遮罩，该抽样不能证明眼区其余暗像素、shader 或实际光照效果；未修改任何龙形贴图。若游戏实测仍不符，应先结合网格 UV 和游戏画面限定虹膜区域，再针对实际使用的纹理制定修改方案。
