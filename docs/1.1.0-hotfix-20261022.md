# 1.1.0 实机反馈修复（2026-10-22）

本轮保持用户指定的 1.1.0 版本，在 main 更新。以当前 Workshop 文件和本机实机反馈为依据，1.0.6 仅作为历史规则说明；不将旧修复直接覆盖到新天家宗仪。天家宗仪当前依赖名为“天家宗仪V0.9beta-宗子维城”。

## 修复和功能保留

- 宫帐庄园：宫帐将 steppe_admin 政体接入 `nhe72_palace_estate`，中华大庄园的建筑定义却只允许 `east_asian_estate`，游戏冲突清单显示后者实际覆盖前者。兼容层以当前中华大庄园建筑文件为底稿，仅给全部 545 个建筑级别追加宫帐庄园类型。建造时间、费用、效果、前置、纹理、升级链和 16 槽布局均保留；不把宫帐角色强行改成原版游牧，不重建现有建筑。补齐两个自定义庄园类型的名称及提示别名，消除标题中的原始键。
- 同级流官：入队允许天朝顶层治下的官僚／行政角色，旧次日归还却要求角色自己是天朝政体，任务因此被跳过。统一入队和执行的有效政府谓词：celestial、bureau、administrative；同时修正日志确证不存在的 `government_use_bureaucracy` 旗标。保留 h_china 顶层约束、任命法、宗藩法精确排除、贵族／租赁／无地保护、当前合法继承人递交及循环保护。没有对全部旧存档头衔执行无依据的清空。
- WoC：原先兼容层将工具条锚定在顶部中央；改为右下角，位于原生及调试地图模式区上方。气候、人口、伯爵领人口／建筑及财政五项功能、开关和宿主条件保持。三项或五项出现取决于当前界面；不会通过隐藏功能来解决位置问题。

全部修改只存在于兼容 Mod，原 Workshop 文件不改。宫帐模块包括建筑覆盖和本地化，可用构建器单独选择组合；其他玩家无需修改原 Mod。
