## 决策结论

1. 六种原生鳞色不是六个独立身体模型。它们共用一个完整飞龙mesh、219骨骼及单套UV，通过独立`.asset`材质引用切换albedo。体型也是同一mesh的11档等比scale，不含六套独立骨架或体型拓扑。
2. 当前实际使用的 `myv_wyvern_double_sided` Effect 走 `PS_attachment`，没有启用 `VARIATIONS_ENABLED`，没有调用皮肤/头发/眼睛palette混色。**只改角色颜色变量或palette数值不能在当前链路实现任务书六类新配色。** 这些变量只是在六张既有diffuse间选择。
3. 最小风险方案为新增六张royal albedo和独立命名的royal pdxmesh/entity/accessory/template；完整复用原mesh、UV、normal、properties、shader与动画。无需重建模型、重绑蒙皮或新造shader。
4. 不能只覆盖正常人物窗口：飞行、奔跑、野外空战、骑乘、紧凑头像、纪念头像有独立选择链。骑乘颜色来自骑手变量 `var:myv_riding_portrait_wyvern` 指向的龙，不能误用骑手身份。各场景都需要独立royal分支且普通分支保持原样。
5. “龙首”必须区分：`myv_compact_head.mesh`是原MYV的紧凑角色头像派生，仍属于活体外观链；`patches/wyvern-capture/mod/gfx/models/artifacts/mm_wyvern_trophies/mm_wyvern_trophy_head.mesh`是winner_77来源的宫廷战利品胸像，本任务不改。

## 材质、贴图通道和共享边界

原身体目录 `W/gfx/models/portraits/myv_wyvern/` 共有7张diffuse（其中无后缀与green逐字节相同）、1张normal、1张properties。全部是2048×2048、未压缩32位BGRA、16,777,344字节，DDS头mipMapCount=0（仅基础级，无完整mip链）。

| 资源/通道 | 当前证据 | 配色时处理 |
|---|---|---|
| diffuse RGB | 原色+鳞片/膜/角质/腹部等细节共用atlas | 新增六张royal版本，保留细节层次 |
| diffuse A | 实际含0–255；green/red/gold/grey/black的alpha逐像素相同；nightmare不同 | 以green基础A逐字节保留，不能把alpha当颜色遮罩重写 |
| normal | R恒255、G/A可变、B恒0；shader以`UnpackRRxGNormal`解码 | 原文件原样复用；不按普通RGB法线重编码 |
| properties R | 33–255，均值250.923；在shader中为散射等分支输入 | 原样复用；当前Effect没开散射/发光分支 |
| properties G | 恒54 | 原生specular输入，保留 |
| properties B | 恒0 | 原生metalness，保留；暗青铜色不意味着整个生物改成金属 |
| properties A | 50–255，均值236.379 | 原生感知粗糙度，保留；高粗糙度有利于避免塑料感 |

通道含义由 `W/gfx/FX/myv_wyvern_portrait.shader` 中 `GetMaterialProperties(Diffuse.rgb, Normal, saturate(Properties.a), Properties.g, Properties.b)` 以及 `G/gfx/FX/cw/lighting_util.fxh` 的函数签名/赋值核对。当前shader专门启用双面膜渲染、背面normal翻转和双面阴影；royal必须保留。不得套用战利品`court` shader的emissive规则。

`W/gfx/FX/myv_wyvern_portrait.shader`虽含 `vPaletteColorSkin/Eyes/Hair`、texture override与`ApplyVariationPatterns`等通用代码，但当前Effect仅定义 `PDX_MESH_BLENDSHAPES`、`DOUBLE_SIDED_ENABLED`，入口`PS_attachment`并不使用palette；仅有条件编译的variation段不能证明现有附件已可按人物tint。原生衣物variation或新建专用shader理论上可再开发，但需要新的遮罩/配置/着色测试，并不比六张albedo更小。结论限于已核实链路，不声称CK3引擎全局不存在任何tint能力。

六张同规格albedo新增约96MiB基础像素数据；不复制身体mesh/动画/normal/properties。若增加完整mip或压缩，需要另验DDS格式及逐mip，不在本审查擅自改变交付格式。
