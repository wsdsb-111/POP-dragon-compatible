# 1.3.4 野外繁育：实施前核查（未实现）

用户要求：三至五月雄龙向同县或邻县可配雌龙实际移动，不改永久巢；双亲饱食至少 60，同县、非近亲、非龙王后，雌龙每年一次 10% 产一枚蛋，成功后冷却五年。同源优先，两端选择都需生效。次年自动孵化；普通龙人口已满时蛋等待；龙王和受保护初始后代不占普通人口配额。初代创造者关系不等于生物亲属，双胞胎与真实近亲不可繁殖。

实际源码边界：

- MYV `myv_wyvern_egg_yearly_pulse` 遍历所有有颜色、活着的持有人且有位置的蛋；成功后延迟 1–364 天调用 `myv_wyvern_egg_scheduled_hatch`。两个入口都必须重新核查野蛋与现有持有人，避免野生蛋进入普通驯化孵化，且转入人类后恢复普通蛋流程。
- 月循环并非引擎直接 `monthly_global_pulse`：`myv_wyvern_monthly_pulse` 每月自调度，kings 有最终覆写。原生 `myv_wyvern_monthly_roaming_effect` 三月回巢，四五月低于 70 的龙可游荡，所以求偶移动应在最终生效的月循环中原生游荡之后进行，不能独立安排不确定先后顺序的月循环。`current_month`、`set_location` 和 `myv_wyvern_hunger` 是现有源码使用的接口。
- `myv_create_stable_bred_wyvern_egg_artifact_effect` 保存真实母父、按 60/40 选择父母颜色，血脉补丁在这个具体蛋上冻结 50% 传奇概率。原 `myv_hatch_wyvern_egg_effect` 创建驯服龙并绑定持有人，不能用于野生孵化。
- kings 最终覆盖的 `myv_create_wyvern_effect` 在创建时调用血脉登记后才可由调用者赋予母父，且内部执行人口修剪。直接调用会让野生子代在真实父母设置前随机获得来源，并可能触发对已有龙的删除；需设计安全的野生幼龙专用创建路径，先建立父母，再调用身份与来源登记，不运行人口裁剪。
- `myv_is_living_wild_wyvern` 的最终 ascension 覆盖已排除被捕、驯服、沉眠及独立龙身；另需排除兽栏、原版传奇龙及真正龙王。独立 bloodline 不应引用可选模块特征；应通过默认/后加载桥接区分王权与受保护人口。原 `myv_can_spawn_natural_wyvern` 统计所有活龙并检查巢数，不能直接代表普通龙出生余量，且同巢幼龙不应新增巢占额。
- 真实蛋由母龙持有时，母龙死亡后 CK3 对该 artifact 的继承、销毁和无主处理尚未证实。必须在实机证实或使用能持久保存的真实蛋载体，才能宣称父母死亡时仍能按原父母孵化；一旦持有人是人类应停止野生自动孵化。

本文件只是源码核查，不代表生产实现、测试或实机验收；无付费请求、游戏启动、Workshop 写入或提交。
