# 1.3.3 龙王实机反馈修复（2026-10-27）

按用户五项截图反馈修复1.3.2，使用独立兼容Mod，不修改原Workshop、游戏或父VOTC应用。用户确认海洋与水双生仍为利维坦、贝西摩斯，埃吉尔为合一后的名字。下述源码修复的自动化、打包和安装结果分别记录；不能以静态检查替代游戏内显示。

## 显示和故事

- 双生/合一王权的动态 `icon/first_valid` 改用DDS文件名。先前参考的 `_traits.info` 示例给出全路径，但本机 `00_traits.txt` 的实际动态图标使用文件名；先前自动化也误将全路径当正确值。现核验四分支、回退与真实DDS均对应，不改变用户图稿或属性。普通角色特质的图标、名字与描述沿原生 `Character.Self`，未为信条组件的 `GetPlayer` 改动人物GUI。
- 两种王权trait通过原生动态desc按王座选择火/地/海/天四份简介；黑白皇说明接入用户原稿，保留原70%部位免伤及其它实际机制说明。海洋原稿的两位名字按用户确认替换，其它故事文字保留。故事不额外生成被弑杀者，也不以叙事触发未经要求的新效果。
- 真正四类王权在分支刷新时移除六个后裔分支trait，保留来源变量；普通龙族从已登记创造王座获得可见分支与双王来源。无可靠来源的旧龙不随机补造历史，新生成入口才可随机创造归属。火1、地2、海3、天4的映射有独立检查。
- 黄金瞳补原生眼睛实体的色遮罩配置，金虹膜清除遗传眼色染色遮罩，保留原RGB与眼白。初始混血家族未必带独立龙瞳trait，因此六个血级的人形还直接选用黄金瞳外观，不额外添加trait或属性；仅带龙瞳trait的普通人形也不再要求额外混血标记。原龙形及升华龙形仍排除，人形flag优先。其它龙饰资源依旧使用现有构建器。[肖像模块记录](1.3.3-portrait-hotfix-module-20261027.md)。
- 身体trait、野生/驯服/传奇面板分类、人物查找器和相关身份称谓通过 `localization/replace` 改为龙族/龙王。新增文件随完整包交付。[祖源模块记录](royal-origin-hotfix-module.md)。

## 四系普通龙族

四个王座各独立等权抽取5/6/7/8/9/10，共20–40条普通龙族，以各苏醒龙王所在地为初始巢穴；这四组不是八位龙王每人额外生成一组。创建前明确王座，避免先随机错配、再留下错误祖源。仅新局pending触发一次，不在重载或每月补生。

原生额外生成的一条野生龙另有独立 `create_character` 后端，新增包装on_action仅在本次成功生成、同时持有原生完成标志与新龙scope时登记来源；旧完成标志、失败或缺scope均不虚构血脉。保持原生地点与性别抽取。

初始造物在批量完成前暂缓人口裁剪，标记后与固定王族一样排除直接人口清理，其它普通龙仍按原设置上限和年龄裁剪。游戏规则说明同步展示这条例外；初始造物仍可能饿死、受伤或被猎杀，并未获得王权/永生。原自然生成和生蛋机制保持。

本版的家谱、醒眠、位置与初始种群需要新开局。旧档保留进度，不强制搬迁、使已苏醒者重新蛰眠、生成新家族或重写人物亲缘；原有王族分支污染在登记/刷新时清除，普通已知来源可补显示，未知保持未知。
