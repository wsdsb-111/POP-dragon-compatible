# 多 Mod 兼容开发日志

## 1.1.0 · 2026-10-21

本轮由原Three-Mod 1.0.6独立工程继续开发，显示名改为“多 Mod 兼容 Mod”。用户要求保留各Mod功能，通过独立补丁追加入口或合并覆盖来兼容，方便其他玩家复用。未编辑上游Workshop文件；按受支持模块组合组包，不要求所有玩家安装全部十个Mod。

### 日期与汉番日历

功能扩展合集3595402176的原生HUD仍绘制`nianhao_text`，而汉番礼制单独实例化年历，旧补丁只屏蔽了东方王朝独立时间层。因此同时出现多段日期。当前合并HUD仅禁止重复旧年号，并把原生普通／多人日期限制为观察者；普通玩家仍使用汉番日历。

独立QA另找出汉番自身的跨作用域反例：边疆文化附庸与汉文化领主的干支、生肖条件可以同时为真。兼容层只将五段文本按现有优先次序互斥显示，未修改年号、触发器或文化资料。专项遍历32种选择器组合和观察者／玩家两态。

### 宫帐模组与庄园

**本轮包含“亳伯奇难题（更理想的宫帐政体）”3805560229的兼容。**其共享庄园按钮使用头衔窗口中的指定庄园上下文；汉番领地页仍调用同名按钮，导致“你的庄园”卡片取不到资料。补丁新增角色专用按钮，仅改领地页调用；宫帐原头衔入口继续使用其指定庄园，不互相替代。

宫帐两个庄园类型覆盖了中华大庄园3601801031的布局，槽位从16项变为7项，日志可见缺失槽位错误。兼容层仅把完整15外槽＋1主槽的顺序、纹理、位置和尺寸合入两种类型，保留宫帐权限、`herd=yes`、基础槽位、费用和背景。有效建筑链的容量与效果不改，不承诺静态定义等于实际已解锁数量。

最初只读检查发现旧档混合了7槽与16槽两套主槽索引；直接换布局不能保证旧档正确。用户随后明确准备新档，本轮按新档统一布局，不执行存档迁移或建筑重建。新档建造及解锁仍待CK3验证。

### Weight of Crown Fork

用户确认地图、伯爵领人口／建筑、财政三组按钮均缺失或被覆盖。源文件中原地图根注册被注释；伯爵领入口存在裁切与外置坐标；财政附加窗不读取原标签切换变量，且标签使用固定x=1250，内阁附加窗与原主面板有几何交叠。

补丁独立注册上方WoC工具条，气候／人口调用原`SetMapMode`和ScriptedGui，伯爵领人口与建筑调用原窗口变量；未复制人口模拟或改税率。两个地图按钮用原通用地图层同样的`CanChangeMapMode`门禁，使宫帐等政体也能使用。财政按钮复用原落地统治者／非部落／非游牧／非冒险者资格，并让原财政窗读取原开关变量。标签改右侧相对停靠，内阁附加窗移出原655宽面板区域。原面板内容、政策和议会任务保留。

### 飞龙、东方服饰、人格与功绩

播放集后置汉番人物窗口覆盖了飞龙原面板接线。合并保留汉番布局与分隔、飞龙专用面板和原人类面板的选择、飞龙羁绊和展开列表、武勇提示，以及More Personality Depth的人物窗口经验钩子。

飞龙的人物查找与交互确认界面保留自定义行和尺寸，同时合入Show Merit Level When Grant Titles的功绩、宗教与文化信息。特质提示以飞龙模板保留伤势／和谐／营养轨道规则，并保留人格特质经验条原显隐规则和Rite API。

东方王朝服饰占用了飞龙新增模板原编号221；东方的221和222保持，飞龙`myv_no_clothes_forced`改用空缺223。原飞龙portrait modifier按模板名称引用，模板名称与无衣物语义不改。未替换DNA、删除东方衣物或关闭飞龙机制。用户按作者要求新开档。

### 可复用边界与验证

通过五个模块组包：基础三Mod、日期HUD、宫帐庄园、Weight入口、飞龙界面。只追加注册或复用原脚本的部分不需要整文件覆盖；没有注入点的GUI与同名基因定义仍提供明确来源的合并覆盖，原文件保留。来源hash分别在三个`patches/*/sources.json`中；未来上游更新须复核，不能把此快照当作任意版本自动兼容。

7组自动化检查及独立QA源码复核通过；已部署独立工程和本地完整兼容包，27份运行文件与相邻描述符hash一致，27项上游来源指纹未变，部署后复跑7组通过。替换前均已备份，详细边界见[实施与验证](1.1.0-verification.md)。真实CK3新档、所有按钮实点、庄园建造／升级、飞龙头像／骑乘／飞行、人口／财政长期效果尚未验收。旧日志早于新加入飞龙与Weight的播放集，不能拿无报错作为它们的运行PASS。没有执行付费请求、远端CI、Workshop上传或GitHub推送。
