## 2 共用技术底座

| 项 | 做法 |
| --- | --- |
| 单位/坐标 | 1 BU = 1 m；代码里全部 mm 常量 ×0.001；Z-up，前方 −Y，右侧 +X，θ 从 −Y 起算 |
| 几何生成 | 自写参数化生成器（[`_lib/relic_geo.py`](_lib/relic_geo.py)）：透镜截面叶片（非对称半宽＋外倾＋尖端倒钩）、任意 3D 脊线薄刃、椭圆墙/锥面壳、扫掠管、链、宝石刻面、鳞板 |
| 为什么不用 op | catalog 里 **没有"任意朝向叶片扫掠/冠刺倒钩"** 的算子（`surface_*` 只接受 z 层叠截面）；几何仍回 `audit_mesh` 门验收 |
| 渲染 | [`_lib/relic_render.py`](_lib/relic_render.py)：正交四视 = Workbench+cavity 灰件（看得清台阶缝隙）；外观 = EEVEE Next 三点光 + AgX |
| 材质 | ambientCG **CC0 1.0**（可商用、无需署名）：Metal042A 金 / Metal042B 暗金 / Metal046A 黑鳞·黑杆 / Metal032 抛光银 / Fabric030 布·纱 / Marble012 大理石·象牙 / Rock030 深岩；BOX 投影免 UV；宝石/熔裂/符文为程序化 |
| 补下载材质 | 5 套（Fabric030、Fabric026、Marble012、Rock030、Metal032），来源/许可/33 张 PNG 哈希见 `materials-cc0\manifest-deepseek-supplement.json`；旧 `manifest.json` 与既有三套未被改动 |
| 串行 | 全程同一 Blender 会话串行建模/渲染；无并发高面数渲染 |

## 3 逐件说明（结构 ↔ 三视图对应）

### 3.1 暴君始祖黑鳞冠 `black_crown`（第一件，无软垫新版）

- **冠圈**：椭圆空心墙，外 384×352、壁厚 30、顶缘按冠刺根部隆起成波浪（`z_top(θ)`）；内圈另有金色内带 —— 对应俯视图的空心环与 INNER BAND 特写。
- **冠刺**：13 根（前后中心 + 5 对）+ 尖端/外缘**倒钩 8 枚** + **12 对金火焰舌**；每根是"透镜截面叶片"，有 4 个自由度：尖端高度、基部半宽、外倾角、尖端侧向钩出。对应三视图要求的**弯曲冠刺**：外倾 2°–36°（越靠侧面越外张）、尖端钩出 0–48 mm。
- **黑鳞**：270 片独立鳞板阵列（19 mm 行距、33 mm 弧距，鳞尖朝下）＋ 熔裂发光条 —— 对应 SCALE TEXTURE 特写。
- **金饰**：每根冠刺沿外缘有金边管（3.6 mm）＋ 前下方下垂金弧饰带 ＋ 内圈金带。
- **龙首**：前中心（面盘＋吻部＋双角＋眉脊＋红眼）＋ 下方三颗红宝石（中 34 mm 高、两侧 20 mm）。
- **材质**：黑鳞=Metal046A 压暗（Value 0.075，金属度 0.32）／金=Metal042A／暗金=Metal042B／红宝石=程序化（IOR 1.78、粗糙 0.08、透射 0.25、微自发光）／熔裂=自发光 14。
- **QA**：boundary 0 / nonmanifold 0 / degenerate 0 / loose 0 / 法线反向 0 / 判不出 0；**自交 151**（装饰层叠，见 §4）。鳞板已拆成 3 个对象以避开插件 256 壳分析上限。
- **与插画的差距**：插画的冠刺更长更锐、尖端有明显倒钩与二次分叉，金色镂空是较粗的立体卷草；我做成"叶片＋金边＋火焰舌"，远看是同一套结构，近看密度不足。黑鳞是规则阵列，插画是不规则手工层次。

## 5 如何复现 / 继续施工

```bash
# 重跑某一件（会把该件目录下的 .blend/渲染/GLB 全部重建）
blender_rt_do(file="…/deepseek-from-scratch/<asset>/build_<x>.py", session="interactive")
```

- 所有尺寸集中在每件脚本顶部常量（或 `crown_spec.py`），改数值即可改形体；`_lib/relic_geo.py` 是七件共用零件库。
- 渲染：`relic_render.render_ortho()` 出四视，`render_beauty()` 出斜角；两者都按包围盒自动取景。
- 材质：`relic_geo.std_materials()` 统一给七件供 M-gold / M-darkgold / M-blackscale / M-steel / M-bronze / M-ruby / M-crack / M-cloth_* / M-marble / M-stone / M-pearl / M-crystal_blue …

**建议的下一步优先级**（我若是你会这样排）：
1. 你先看七件正交图与斜角图，指出"哪一件的哪个部件不对"（最省时间）；
2. 王冠按你的反馈先修外形（冠刺曲率/高度/开孔），它是标杆件；
3. 逐件把"概括件"升级：龙首→雕刻块面、龙鳞→逐片不规则、镂空金饰→立体卷草；
4. 最后才谈 CK3 导出与实机（届时由你或另一位执行）。
