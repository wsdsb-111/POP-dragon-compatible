# 德拉克斯尔与瑟林德：宫廷展示模型

两件原创静态三维模型，包含一体式陈列架。PNG 为实际网格与颜色贴图的软件渲染，不是概念插画或 CK3 实机截图。

- 德拉克斯尔：332,662 三角形，增加倒角与层次的双刃、中央骨质镶嵌、细部龙首与龙牙护手、卷曲角形侧翼、缠皮握柄及切面红宝石。
- 瑟林德：433,096 三角形，椭圆截面反曲弓臂、30片独立龙鳞、金属包边、缠绳握把、端部角饰和三维弓弦。
- 陈列架：深色木质、金属包边、镶钉、托钩和底部纹章。每件包含自己的支架，court visual 不追加引擎 pedestal，避免叠架。
- 原生 Y-up，正面朝 -X，对照原版宫廷武器尺度：高度约116／119单位，地面在Y=0。不是人物手持或战斗动画资源。
- 共享4096×4096颜色、法线和属性贴图；游戏资源使用完整13级mip的DXT5 DDS与court shader。修正RRxG通道和粗糙度，normal.B为0，消除错误自发光。

`draxel.glb` / `serind.glb` 内嵌颜色、金属度／粗糙度及标准切线法线贴图；OBJ通过 `trophies.mtl` 引用同目录颜色贴图。正面、斜角、背面预览与 `contact-sheet.png` 可检查遮挡。`models.json` 记录顶点、三角形、包围盒和原生mesh SHA-256。

重建：

```powershell
python scripts/build-dragon-weapon-models.py
```

依赖 NumPy、Pillow；复用仓库中已校验的网格基元和可编辑格式输出，不读取原版几何，也不修改 Workshop 文件。原生尺寸参考与重铸规则见[本版记录](../../../docs/1.1.6-dragon-court-models-20261025.md)。
